# 战场设施模型命名规范

把 GLB 文件按下面的名字放进本文件夹（`src/assets/scene/`），重启 dev 后游戏会自动加载，
在 **3D 战场**（指挥制 / 3D 战场模式）中以线条风格渲染。**无需改代码即可新增。**

> 本文件夹只放**静态设施**（中继站、基地、要塞、地形标记）。
> 舰船模型请放 `src/assets/ship/`——两套管线不同：舰船模型会自动旋转对齐 + 舰首翻转，
> 设施模型不做任何自动旋转（保留建模朝向），混放会导致设施躺倒或朝向错乱。

## 文件命名：`{设施键}.glb`

| 文件名 | 替代的战场对象 | 默认尺寸（hexR 倍数） | 视觉现状 |
|--------|---------------|---------------------|---------|
| `relay.glb` | 中继补给站（星空中继 / 补给链中继） | 1.6（悬浮 0.6×自身高） | 陀螺仪双环+核心球 |
| `base.glb` | 出生点 / 司令部基地（castlePos 处） | 3.2（贴地） | 线框六棱柱+八面体核心 |
| `fortress.glb` | 要塞地块（伊谢尔伦要塞等，**只摆要塞群中心格**） | 4.5（贴地） | 八面体 |
| `planet.glb` | 宜居行星 | 1.2（球体直径） | 绿色球 |
| `mine.glb` | 资源矿点（gold_mine） | 0.9 | 黄色八面体 |
| `tower.glb` | 防御塔 | 0.9 | 紫色圆锥 |
| `pier.glb` | 跳跃节点 / 码头 | 1.2 | 蓝色环 |
| `castle.glb` | castle 地块定位标记 | 1.0 | 青色细光柱 |

**阵营差异（可选）**：`{设施键}_empire.glb` / `{设施键}_alliance.glb`
（如 `relay_empire.glb`、`base_alliance.glb`）优先于通用名使用。
不提供则统一用 `{设施键}.glb`，并按所属阵营自动染色（体色/线框色跟随阵营色）。

**查找优先级**：`{键}_{阵营}.glb` → `{键}.glb` → 程序化兜底造型（现有形状）。

**要塞摆位规则**：要塞是 7 连格（中心 + 6 邻格）。有 `fortress.glb` 时**只在中心格摆 1 座**
（中心格自动判定 = 邻接要塞格最多者），避免出现"7 座要塞并排"。所以要塞模型建议按
"一整座要塞"建模，尺寸 `size` 按要塞整体宽度给（4.5 ≈ 覆盖 2~3 个六角格）。

## 不按规范命名 / 暂不使用的模型（有兜底，不会报错）

把任意文件名（如 `空间站_v2.glb`、`station_A.glb`）丢进本文件夹是**安全**的：

| 场景 | 行为 |
|------|------|
| 巡览展示 | **照常展示** —— 「模型巡览 → 3D 建筑 · 战场设施」板块会列出本文件夹**全部** `.glb`，标题用文件名，不看命名规范 |
| 尺寸 | 走**兜底尺寸 2.0×hexR**（可单独设，见下）；标签会标注「（兜底）」 |
| 战场 | **不认识就不使用**：不会替换任何设施，也不会报错，战斗逻辑零影响 |

### 想单独控制尺寸（不改文件名）

在 `src/game/three/sceneProps.ts` 的 `SCENE_PROP_CONFIG` 里按**文件名（不含 .glb）**加一行：

```ts
export const SCENE_PROP_CONFIG = {
  relay:    { size: 1.6, lift: 0.6 },
  ...
  '空间站_v2': { size: 4.5 },        // ← 按文件名加，巡览/战场都按这个尺寸
  'station_A': { size: 3.0, yaw: 90 },
};
```

**尺寸优先级（巡览与战场同一口径，不会出现两处不一致）**：

```
① 文件自身登记（SCENE_PROP_CONFIG[文件名]）      ← 最具体，优先
② 绑定槽位登记（SCENE_PROP_CONFIG[设施键]）      ← 文件未登记时，随它绑定的设施
③ 兜底 DEFAULT_SCENE_PROP_SIZE = 2.0×hexR
```

例：`my_station.glb` 绑到 `relay` 且你给它单独登记了 `size: 5` → 用 **5**；
若没给它登记 → 用 relay 的 **1.6**；既没登记也没绑定 → **2.0（兜底）**。

### 想用不规范命名的模型上战场（不改文件名）

在同一个文件的 `SCENE_PROP_BINDING` 里绑一行（把设施键指向你的文件名）：

```ts
export const SCENE_PROP_BINDING = {
  relay: '空间站_v2',            // 中继站改用 空间站_v2.glb
  base:  ['base_v2', 'base'],    // 优先 base_v2.glb，没有就退到 base.glb
};
```

绑定优先于命名约定（绑定 → `{键}_{阵营}.glb` → `{键}.glb`）。绑定后巡览标签会显示
`→ 绑定为 relay`，便于确认生效。

## 尺寸控制（只改一个数字）

打开 `src/game/three/sceneProps.ts`，改 `SCENE_PROP_CONFIG` 里对应设施的 `size`：

```ts
export const SCENE_PROP_CONFIG = {
  relay:    { size: 1.6, lift: 0.6 },
  base:     { size: 3.2 },
  fortress: { size: 4.5 },
  ...
};
```

- **`size`**：模型**最长边**的战场长度，单位 = `hexR` 倍数（hexR = 六角格外接圆半径，指挥制约 50）。
  缩放是**等比**的——只改这一个数字，模型的长/宽/高按原建模比例同步缩放。
- **`lift`**：悬浮高度，单位 = **旋转后**模型高度倍数。`0`/缺省 = 底面贴地；`0.6` = 离地 0.6 倍自身高度（空间站用）。
- **`yaw`**：朝向修正（度，绕 **Y** 轴）。模型正面朝错方向时填 90 / 180 / -90。
- **`pitch`**：绕 **X** 轴（度）。**"竖起来"就用它**——平躺的环 / 盘 / 门类模型填 `90` 即立起（例：`stargate2`）。
- **`roll`**：绕 **Z** 轴（度）。三轴旋转序固定 **YXZ**（先竖起翻正、最后定朝向）⇒ `yaw` 恒为绕世界竖直轴，符合直觉。
- **`spinY`**：**绕模型竖向中线持续自转**（度/秒）—— "360° 缓慢旋转"最常用，6 秒一圈填 `60`。
- **`spinX` / `spinZ`**：绕 X / Z 轴的翻滚（度/秒）。翻滚会改变模型高度 ⇒ 代码**每帧重算贴地**，
  模型始终"贴着地面翻滚"，不会穿地。

> 自旋按**真实时间**推进（不随战斗倍速缩放），与中继站 / 要塞核心的程序化自旋同口径。

### 竖起来 / 加动画（完整示例）

```ts
export const SCENE_PROP_CONFIG: Record<string, ScenePropConfig> = {
  // … 既有设施 …

  // 平躺的星门 → 竖起来 + 绕竖轴缓慢自转（12°/s ≈ 30 秒一圈）
  stargate2: { size: 4.0, pitch: 90, spinY: 12 },

  // 悬浮空间站 → 抬离地面 0.6 倍自身高 + 绕竖轴快转（60°/s = 6 秒一圈）
  '空间站_v2': { size: 3.0, lift: 0.6, spinY: 60 },

  // 翻滚的大环 → 绕横轴滚（贴地滚动，代码每帧重算贴地所以不会陷地）
  'ring_gate': { size: 5.0, spinX: 30 },
};
```

**尺寸与动画的唯一调整入口都是上表**（`src/game/three/sceneProps.ts`）。巡览里改完能直接看到效果：
选中建筑 → 试转「朝向 / 竖起 / 自旋预设」→ 点「📋 复制配置行」→ 粘回本表对应位置。

## 模型规格要求

| 项目 | 要求 |
|------|------|
| 格式 | GLB（二进制 glTF 2.0），不要 Draco 压缩 |
| 面数 | ≤ 5 万三角面为宜（超过 20 万面将跳过轮廓线框生成） |
| 贴图 | 可有可无（渲染时贴图被丢弃，走"半透明体 + 轮廓线框"风格） |
| 朝向 | **保留建模朝向，不做自动翻转**。建议：模型正前方朝 -Z、上方为 +Y、底面在 y=0 平面（不满足也行，代码按包围盒自动贴地） |
| 比例 | 不要求（按包围盒最长边归一化到 `size` 指定的战场尺寸） |

## 注意事项

- 新增/替换文件后必须**重启 dev**（`wails dev` 或 `vite dev`）——文件列表在构建期收集
- 模型异步加载：就绪前该位置不显示（几秒内出现），控制台日志 `[sceneProps] 设施模型就绪 xxx.glb: N tris`
- 设施模型只在 **3D 渲染层**生效；2D 模式（hex / CRT 线框）仍走原有程序化图形
- 删除某文件即回退到程序化兜底造型，无需改代码
