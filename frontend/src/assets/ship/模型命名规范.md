# 战舰模型命名规范

把 GLB 文件按下面的名字放进本文件夹（`src/assets/ship/`），刷新游戏即可自动加载渲染为线条风格。**无需改任何代码。**

## 文件命名：`{阵营}_{舰种}.glb`

| 文件名 | 舰种 | 说明 |
|--------|------|------|
| `empire_battleship.glb` | 帝国·战列舰 | ✅ 已接入 |
| `empire_carrier.glb` | 帝国·航母（突击） | ✅ 已接入 |
| `empire_cruiser.glb` | 帝国·巡洋舰 | ✅ 已接入 |
| `empire_destroyer.glb` | 帝国·驱逐舰 | ✅ 已接入 |
| `empire_fast_battleship.glb` | 帝国·高速战列舰 | ✅ 已接入 |
| `empire_fighter.glb` | 帝国·舰载机（王尔古雷） |  |
| `empire_supply.glb` | 帝国·补给运输舰 | ✅ 已接入 |
| `alliance_battleship.glb` | 同盟·战列舰 | ✅ 已接入 |
| `alliance_carrier.glb` | 同盟·航母（突击） | ✅ 已接入 |
| `alliance_cruiser.glb` | 同盟·巡洋舰 | |
| `alliance_destroyer.glb` | 同盟·驱逐舰 | ✅ 已接入 |
| `alliance_fighter.glb` | 同盟·舰载机（斯巴达尼恩） |  |
| `alliance_supply.glb` | 同盟·补给运输舰 | |

> 阵营差异说明：同盟无高速战列舰，`alliance_fast_battleship.glb` 不会被使用。

**通用模型**（两阵营共用一个外形）：直接命名 `{舰种}.glb`，如 `battleship.glb`、`carrier.glb`。
查找优先级：`阵营_舰种.glb` → `舰种.glb` → 程序化兜底造型。

## 专属旗舰命名：`flagship_{key}.glb`

提督数据里带旗舰名的提督（`admiralsData.ts` 的 `flagshipName` 字段），其舰队第一艘舰（旗舰）会优先查找专属模型：

| 旗舰中文名 | 文件名 | 所属提督 |
|-----------|--------|---------|
| 伯伦希尔 | `flagship_brunhild.glb` | 莱因哈特 |
| 休伯利安 | `flagship_hyperion.glb` | 杨威利 |

**新增专属旗舰两步**：
1. 建好模型放入本文件夹：`flagship_{key}.glb`（key 用英文或拼音，如 `flagship_beowulf.glb`）
2. 共享模块 **`src/game/three/shipModels.ts`** 的 `FLAGSHIP_MODEL_ALIAS` 表登记一行：`'旗舰中文名': 'key'`

旗舰名以 `admiralsData.ts` 各提督的 `flagshipName` 为准（如 盘古、王虎、火龙、鲁斯坦 等）。未登记或无模型的旗舰自动落回阵营战列舰模型 → 通用战列舰模型 → 程序化造型。

## 模型规格要求

| 项目 | 要求 |
|------|------|
| 格式 | GLB（二进制 glTF 2.0），不要 Draco 压缩 |
| 面数 | **≤ 5 万三角面**（Blender Decimate 0.02~0.05） |
| 文件大小 | ≤ 2MB |
| 贴图 | 可有可无（渲染时贴图会被丢弃，走阵营色+线框风格） |
| 朝向 | 默认自动转 180°（Blender 导出的模型舰首普遍朝 +Z，战场约定朝 -Z）。个别模型朝向不对时，见下方「修正单舰朝向」 |
| 比例 | 不严格要求（自动按包围盒归一化到该舰种战场尺寸） |

## 修正单舰朝向（不需要改任何逻辑代码）

朝向修正表在 **`src/game/three/shipModels.ts`**：

```ts
export const SHIP_MODEL_YAW_FIX: Record<string, number> = {
  //  'flagship_xxx.glb': 0,     // 该模型导出时已朝 -Z，取消默认 180°
  //  'flagship_yyy.glb': 90,    // 该模型朝 +X，转 90° 使舰首朝 -Z
};
export const SHIP_MODEL_DEFAULT_YAW = 180;   // 未登记的一律按 180°
```

角度含义（绕竖直轴 Y，舰首最终要指向 **-Z**）：

| 姿态 | 模型导出时舰首朝向 | 填 |
|------|------------------|----|
| 正立 | +Z（Blender 默认） | 180（默认，不用填） |
| 正立 | -Z | 0 |
| 正立 | +X | 90 |
| 正立 | -X | 270（或 -90） |
| 舰首朝天/朝地 | ±Y | 不要用朝向表解决，需回 Blender 把模型放正 |

### 三步定位正确角度（巡览内试转）

1. 进游戏 → 打开 **模型巡览** → 找到那艘舰，**单击它**（拖拽超过 5px 不算点击）
2. HUD 出现「朝向修正」行，点 `0° / 90° / 180° / 270° / -90°` 试转，观察 **橙色尾焰锥**：
   - 尾焰落在舰体**最尾端**（远离舰首）= 正确
   - 尾焰跑到舰首 → 差 180°
   - 尾焰在舰体侧面 → 差 ±90°
3. 角度对了 → 点 **「📋 复制配置行」**，控制台会打印一行 `'文件名.glb': 角度,`
   把它粘进 `shipModels.ts` 的 `SHIP_MODEL_YAW_FIX` 表 → **重启 `wails dev`** 生效

> 为什么要在加载时烘焙而不是运行时旋转：朝向在几何体上烘焙一次（`runShipModelLoad` 内 `rotateY`），
> **巡览与战场共用同一份注册表**，改一处两处同时正确，不会出现"巡览对了战场还是错的"。
> 巡览里的试转按钮只作用于画面预览，不会写回注册表。


## 注意事项

- 新增文件后如果没生效，**重启一次 `wails dev`**（文件列表在构建时收集）
- 模型加载是异步的：就绪前场上该型舰先显示程序化兜底造型，就绪后**自动原地换装**
- 控制台会打印每艘模型的就绪日志：`舰船模型就绪 xxx.glb: N tris`
