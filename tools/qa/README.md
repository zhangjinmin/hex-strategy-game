# tools/qa — 质量监管的独立台架

本目录存放**可复用**的验收工具（不是一次性脚本）。纪律：
- 每个工具必须能独立跑：`node tools/qa/<name>.cjs` → 输出 PASS/FAIL 明细，退出码 0/1；
- 不允许 import `frontend/**` 的实现（期望值必须独立复算，见验收判据四条之①）；
- 自带自测（已知答案 ≥3、其中至少 1 命中 1 不命中），跑不崩不等于跑得对；
- 临时脚本用完即删，不留在本目录。

| 工具 | 用途 | 调用 |
|---|---|---|
| `wedge-view-oracle.cjs` | 楔形阵「读不读得出三角」的独立几何对拍器：自己重写排宽/足迹/层数/层距 + 相机与针孔投影 + Spearman；输出仰角×相对方位二维扫描、判定绑定项、门限解析推导；复算上游 A/C/D 结论 | `node tools/qa/wedge-view-oracle.cjs`（exit 0 = 全绿） |

## wedge-view-oracle.cjs 的四项判据

| 代号 | 判据 | 门限 |
|---|---|---|
| S1 `planeAspect` | 压平投影（layers=1）的 纵跨/横跨 | ∈ [0.30, 0.80] |
| S2 `rowOrder` / `minSep` | 各排在屏幕上必须"叠"且可分辨 | \|Spearman(排号,屏幕y)\| ≥ 0.9 且相邻排间距 ≥ 4px |
| S3 `layerSmear` | 队内叠层厚度投影 / 纵深投影 | ≤ 0.5（解析等价 `tan(仰角) ≥ 2·厚度/纵深`） |
| S4 `binSpans` | 探针同口径（16 层 + 纵向 6 等分箱）跨度单调性 | \|Spearman\| ≥ 0.9 且逆序 ≤1 —— **只作线索，不作门禁**（δ=15° 时实测 −0.26，对姿态响应非单调） |

已知局限（写进报告，不得默认忽略）：
- 16 层用确定性去相关散点替代产线 R2 序列（结论只依赖"层号与排号去相关"这一规格性质）；
- 相机距离固定 600（= `hexR*12`），与入场聚焦的小距离不同，透视放大率会有差异；
- 只能判"投影是否可读"，判不了"好不好看" —— 视觉交付必须另外要求实际渲染帧 + 真人路径。
