# 增量 PRD：军议瘦身 + 行政院补全 + 星球右键本地化

> **项目**: 银河英雄传说 策略游戏 (hex-strategy-game)
> **技术栈**: Vue 3 + Phaser + Pinia + TypeScript
> **版本**: v3.0（增量）
> **日期**: 2025-07
> **前置文档**: `PRD_军议重构_行政系统_职位职权_舰队归属.md`（第二轮 SOP 已交付）

---

## 1. 产品目标

| # | 目标 | 度量标准 |
|---|------|---------|
| G-1 | **军议职责聚焦**：将军议从12条提案瘦身为7条"战略令"（需授权/表决的一次性决策），将5条"内政执行类"操作迁出至行政院日常执行，使军议回归"重大战略决策"定位 | 军议面板只展示7种提案类型；月度生成逻辑只从7种中选取 |
| G-2 | **行政院功能补全**：补全外交tab和情报tab的完整交互，并在财政/科技tab新增承接迁出操作的按钮，使行政院成为"日常内政执行"的一站式面板 | 6个tab全部可用（无灰色占位）；5个迁出操作在行政院中有对应入口 |
| G-3 | **星球本地化操作**：将星球右键菜单从"行政(toast占位)+驻守"升级为针对单星球的本地化操作面板（友方7项/敌方3项），让玩家能对具体星球进行精细化管理 | 友方节点右键弹出7项本地操作；敌方/中立节点右键弹出3项情报操作 |

## 2. 用户故事

| # | 角色 | 故事 | 价值 |
|---|------|------|------|
| US-1 | 玩家 | 作为玩家，我希望军议只处理需要投票表决的重大战略决策（侵攻、防卫、征兵、人事、军费、士气、要塞），而日常内政（收税、后勤、科技、情报、外交）在行政院直接点按钮执行，这样两个系统职责清晰不混乱 | 系统清晰度 |
| US-2 | 玩家 | 作为玩家，我希望在行政院外交tab能看到与各阵营的关系值、能对外交施压、能查看当前条约，而不是一个灰色占位页 | 功能完整性 |

| US-4 | 玩家 | 作为玩家，我希望右键点击友方星球时能弹出本地操作面板，可以针对该星球征收特别税、强化治安、投资民生、要塞化等，而不是只有一个"功能开发中"的toast | 操作精细度 |
| US-5 | 玩家 | 作为玩家，我希望右键点击敌方/中立星球时能执行侦察、渗透、策反等情报操作，这样情报系统有实际的游戏玩法 | 策略深度 |

## 4. 军议瘦身方案

### 4.1 保留的7条战略令

| 类型 | 名称 | 定位 |
|------|------|------|
| `invasion` | 战略侵攻动员 | 进攻授权，Warp速度+30%/15天，士气+20 |
| `defense` | 星域防卫令 | 防御授权，指定节点防御HP+100%/30天 |
| `conscription` | 扩大强制征兵令 | 兵源+20%，士气-15 |
| `morale_boost` | 全军士气鼓舞令 | 全军士气+25，消耗₮1000 |
| `personnel` | 人事任免令 | 任免提督职位，影响忠诚度 |
| `budget` | 申请特别军费 | 国库+₮5000 |
| `fortify` | 要塞强化令 | 指定节点防御HP+50%（永久），消耗₮4000 |

### 4.2 迁出的5条内政执行类

| 原类型 | 迁入位置 | 迁入形态 | 效果（与原提案一致） |
|--------|---------|---------|---------------------|
| `tax` | 财政tab | 已有战争附加税开关覆盖 | warTaxRate 0↔0.15 切换，治安-0.5/日 |
| `logistics` | 财政tab | 新增"后勤改革"按钮 | 补给消耗-30%/30天，消耗₮2000 |
| `tech_mobilize` | 科技tab | 新增"科技动员"按钮 | 研发速度×2/30天，消耗₮3000 |
| `intel_op` | 情报tab | 新增"情报行动"按钮 | 情报等级+1/15天，消耗₮1000 |
| `diplomat_op` | 外交tab | 新增"外交施压"按钮 | 目标阵营关系+20，消耗₮500 |

### 4.3 瘦身涉及的代码改动

| 文件 | 改动 |

## 6. 本地化操作效果定义

### 6.1 友方节点操作（7项）

| # | 操作 | 效果 | 消耗 | 约束 | 冷却 |
|---|------|------|------|------|------|
| L1 | 征收特别税 | 国库+₮500，该节点 security-5 | 无 | 国库不为负 | 10天 |
| L2 | 强化治安 | 该节点 security+15 | ₮300 | 该节点需有己方舰队驻留（garrisonFleets非空） | 无 |
| L3 | 民生投资 | 该节点 economy+150（约+3归一化） | ₮800 | 国库≥₮800 | 无 |
| L4 | 要塞化 | 该节点 defenseHp/maxDefenseHp ×1.5，defenseTurrets+10 | ₮4000 | 国库≥₮4000，每节点仅限1次 | 永久 |
| L5 | 设为防卫司令部 | 该节点治安恢复×3、补给恢复×2；设置 `assignedNodeId` | 无 | 需有 defense_commander 职位提督；每阵营仅1个司令部 | — |
| L6 | 紧急征召 | 该节点所属舰队兵源+5%，该节点所属舰队 morale-10 | 无 | 该节点需有己方舰队驻留 | 15天 |
| L7 | 情报搜集 | 揭示与该节点相邻的所有敌方节点驻军信息（临时） | ₮200 | 国库≥₮200 | 无 |

### 6.2 敌方/中立节点操作（3项）

| # | 操作 | 效果 | 消耗 | 约束 | 冷却 |
|---|------|------|------|------|------|
| E1 | 侦察 | 临时显示该节点舰队数量（维持到下次日结算） | ₮200 | 国库≥₮200 | 无 |
| E2 | 渗透 | 该节点持续可见15天（加入 `revealedFleets` 监控列表） | ₮800 | 情报等级≥basic（Lv.2）；国库≥₮800 | 无 |
| E3 | 策反 | 降低该节点守军忠诚度20-40（随机），失败概率40% | ₮1500 | 情报等级≥detailed（Lv.3）；国库≥₮1500 | 30天 |

### 6.3 操作权限矩阵

| 职位 | 友方L1-L7 | 敌方E1-E3 | 行政院迁出操作 |
|------|-----------|-----------|--------------|
| emperor / council | 全部 | 全部 | 全部 |
| prime_minister | L1,L3,L5 | E1 | 后勤改革、外交施压 |
| military_minister | L2,L4,L6 | E1 | 后勤改革、科技动员 |
