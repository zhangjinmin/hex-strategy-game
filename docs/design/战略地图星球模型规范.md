# 战略地图星球/要塞 3D 模型规范

> 制定时间：2026-09-05
> 适用：`ThreeStrategicMap.ts` 战略层星图节点

## 一、文件存放位置

```
frontend/src/assets/planet/
```

与现有 2D 贴图（`1.png` / `14.png` …）同目录，3D 模型另用 `.glb` 扩展名，互不冲突。

## 二、命名规则

```
{节点id}.glb
```

**直接用 `mapTopologyData.ts` 里的节点 id 命名**，不用中文名（避免编码/大小写问题）。

| 节点 | id | 文件名 |
|---|---|---|
| 伊谢尔伦 | 1 | `1.glb` |
| （示例）海尼森 | ? | `{id}.glb` |

**已实现的特例**（当前代码中登记）：

```ts
// frontend/src/game/three/planetModels.ts
export const PLANET_MODEL_MAP: Record<number, string> = {
  1: '1.glb',   // 伊谢尔伦要塞
};
```

新增要塞/星球：把 glb 放进 `assets/planet/`，在 `PLANET_MODEL_MAP` 加一行 `{ id: '{id}.glb' }` 即可，**不用改 ThreeStrategicMap.ts**。

## 三、模型要求（重要）

### 3.1 材质：不使用模型自带材质 ✅（按你的要求）

代码会**丢弃 GLB 里的所有材质**，改用战略层统一的阵营色材质：

- 原因 1：你要压缩材质减小体积，模型里的材质无意义
- 原因 2：战略地图是"全息沙盘"风格，统一材质才能与其他星球视觉一致
- 实现：`planetModels.ts` 加载后遍历子节点，替换为 `MeshPhongMaterial`（阵营色 + 自发光 + 加色混合），并叠加 `EdgesGeometry` 线框

**所以你导出时材质随意**（可不带材质、可带默认材质），不影响最终效果。

### 3.2 几何：只取第一个有效 Mesh

- 代码取 GLB 中**体积最大的 Mesh**（若多部件会自动合并候选）
- **建议导出为单一 Mesh**，避免多余部件干扰

### 3.3 尺寸：自动归一化

- 代码会把模型**最长轴归一化到节点半径**（fortress = 1.0 世界单位）
- 所以模型导出尺寸随意，不用手工对齐

### 3.4 朝向：无需预处理

- 与舰船模型一样，若朝向不对，在 `planetModels.ts` 的 `PLANET_MODEL_FLIP` 登记豁免即可

## 四、旋转（旋绕效果）

**无需在模型里做任何处理。**

战略层节点 Group 已有自转机制（`ThreeStrategicMap.ts:1196` 生成 `userData.axis` / `userData.spin`，`1891` 行每帧 `quaternion.premultiply`）。

替换模型时，模型 Mesh 直接 `add` 进该 Group，**自动获得与其他星球完全一致的旋转**，无需额外代码。
