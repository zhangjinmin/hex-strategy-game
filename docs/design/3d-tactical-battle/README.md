## 1. 本文档的立场

本次改造是**纯呈现层改造**：战斗规则、数值、AI 零改动。但呈现层决定玩家能读到什么信息，进而决定玩家的决策质量。**"规则没变"不等于"游戏没变"**——同一套规则在 2D 俯视与 3D 透视下，玩家的决策质量可以相差一个量级。本文档守的就是这条线。

因此本文档的设计基线不是"3D 好不好看"，而是：

> **2D 俯视下玩家能免费得到的信息，3D 下不得以任何形式丢失。**
> 丢失的必须以等价成本补回，或明确记录为"已知退化"。

## 4. 设计原则（4 条，用于后续所有争议裁决）

1. **信息不因透视而丢失。** 2D 俯视下"整个战场都在屏幕内、所有单位等大"是免费午餐。3D 下这条不成立，必须用**恒定屏幕尺寸 + 信息 LOD + 2D 雷达**三件套补回。
2. **绝不让颜色成为唯一编码。** 所有阵营 / 状态 / 事件信息必须有形状或位置的冗余编码。这是色盲可访问性的硬要求，也是暗色 + 半透明 + bloom 环境下所有人的可读性要求。
3. **相机是可读性的敌人，也是工具。** 默认给一个"够用的固定视角"，把自由旋转做成进阶能力，并始终保留一键回到正俯视（2D 等价可读性）的出口。
4. **玩家永远能关掉任何东西。** 任何自动镜头运动、任何特效、任何后处理，都必须能归零，且归零后游戏完全可玩。
