日期：2026-10-14。用户明确要求：抛掉之前版本的过程，用自己的方案。
范围：舰队级运动学 + 每舰位置解算。**不碰**伤害、AI 决策、渲染 LOD。

---

## 1. 为什么之前四轮都失败

v70 / v71 / v72 连续三轮改错（v72 承认并修正前两轮）。复盘根因：

**所有三轮都在「追槽位」架构内调参数。**

当前架构（`BattleScene.update` 舰队循环）：

```
fleet.x/y              ← 质心，按推力积分移动（v += (vd−v)·a·dt）
fleet.facingSmooth     ← 舰首朝向，追 fAngle
fleet.formFacing       ← 阵面朝向，追 facingSmooth        ← 补丁战场
fAngle                 ← 火控解算（朝敌/朝目标），每帧重算
每舰位置 = 中心 + rotate(部署偏移, formFacing)
每舰用 stepShipSlotFollow 追该位置                        ← 补丁战场
```

**四个量（fAngle / facingSmooth / formFacing / 位移方向）互相耦合，任一变则全变。**
所有观感问题（阵型指向与移动方向不一致、公转画圈、挤压、瞬间换向）都是这个耦合的症状。

⇒ **调参无法收敛，因为问题在结构。**

## 2. 第一性原理：太空舰队移动的真实物理

| 物理事实 | 对游戏的含义 |
|---|---|
| 真空无阻力 | 不给推力就匀速直行；停船必须**反向推力** |
| 推力有方向和大小上限 | 速度变化率受限 ⇒ 起步慢、停船慢、改向慢 |
| 转向靠力矩（姿控推力器） | **质心不动**，只转姿态 ⇒ 原地转向是物理正确的 |
| 舰队 = 多个独立个体 | 不是刚体。但玩家感知上希望它是"一个整体" |
| **保持编队需要横向速度** | 外翼舰转向时必须画弧线（`v_外翼 = ω × 半宽`） |

**关键约束（本方案的核心）**：

```
编队不散架的物理条件：ω × 编队半宽 ≤ 舰船最大速度
```

即：**转向角速度受编队尺寸约束**，不是自由参数。一支宽 400px 的战列编队，
若战列 vMax=0.22px/帧，则 `ω ≤ 0.22/200 = 0.0011 rad/帧` ⇒ 180° 掉头需 47.5s。

这解释了为什么"掉头该慢"——**不是参数没调好，是物理要求**。

## 3. 我的方案：舰队刚体模型

### 3.1 核心思路

**把舰队当作刚体：一个质心位置 + 一个朝向。每艘船是刚体上的点，位置由公式直接给出，不追。**

```
状态：fleet.x, fleet.y, fleet.heading, fleet.vx, fleet.vy, fleet.omega

每帧积分：
  推力 → 线加速度 a = thrustDir × accel
  力矩 → 角加速度 α = torque / inertia
  v += a·dt;  x += v·dt
  ω += α·dt;  ω *= (1−drag·dt);  heading += ω·dt

每艘船（**公式直算，无追踪**）：
  ship.x = fleet.x + cos(heading)·ox − sin(heading)·oy
  ship.y = fleet.y + sin(heading)·ox + cos(heading)·oy
  其中 (ox, oy) = 部署期固定的阵型偏移

每艘船舰首（独立，追火控目标）：
  ship.heading += clamp(fireTarget − ship.heading, ±turretRate·dt)
```

### 3.2 这个方案消灭了什么

| 旧机制 | 新方案 | 消除的问题 |
|---|---|---|
| `formFacing` 阵面朝向 | **删除**（阵面 = 舰队朝向，一体的） | 阵型指向与移动方向不一致 |
| `stepShipSlotFollow` 追槽位 | **公式直算** | 挤压、画圈、抖动、`_slotGap` |
| 阵型 morph 插值过渡 | 偏移量短时插值 | morph 与槽位竞争的 bug |
| `facingSmooth` 追 `fAngle` | 舰首 = 舰队朝向（刚体姿态） | 火控拽舰首、瞬间换向 |
| `REFORM_SLOT_GAP_PX` / `maxSlotGap` | **删除** | 阈值调不准 |
| `_slotFlip` / 格位反转 | 由偏移插值自然产生 | 首尾切换的各种补丁 |

**净效果：删除 6 个耦合机制，新增 1 个刚体积分。**

### 3.3 转向时"画弧线"是物理必然，不再是 bug

旧架构把"外翼舰画弧线"当作要修的问题（于是有了 v70 瞬跳、v71 限速、v72 解耦）。
新架构下这是**正确的物理**：舰队转向，外翼舰划弧以保持编队，弧线半径 = 编队半宽。

**唯一要保证的是弧线速度不超舰船推力上限** —— 这就是 §2 的核心约束。

### 3.4 阵型切换

切换阵型 = 改变每艘船的部署偏移 `(ox, oy)`。

物理上船要机动到新位置。实现：偏移量在 `FORMATION_MORPH_DUR` 内插值，
每艘船位置仍由公式直算（只是 ox/oy 在变）⇒ 船沿直线走到新槽位，无追踪误差。

## 4. 关键参数（由物理约束导出）

### 4.1 编队尺寸 → 角速度上限

```
半宽 halfW = 阵型最大横向跨度 / 2   （line 阵 10 舰 ≈ 250px）
ω_max_fleet = vMax_dominant / halfW × SAFETY
```

| 编队半宽 | 战列 vMax=0.22 | ω_max | 180° 掉头 |
|---|---|---|---|
| 100px | 0.22 | 0.0022 | 23.7s |
| 200px | 0.22 | 0.0011 | 47.5s |
| 400px | 0.22 | 0.00055 | 95s ← 太长 |

**问题**：大编队掉头会慢到不可玩。

**解法（重要设计决策）**：允许**两种转向模式**，由玩家/AI 选择：

| 模式 | 行为 | ω | 代价 |
|---|---|---|---|
| **紧凑转**（turn） | 编队先收拢到半宽 1/2，再转 | 2× | 收拢需 3~5s，期间火力下降 |
| **松散转**（wheel） | 不收拢直接转，外翼全速划弧 | 1× | 外翼舰可能被拉开（若弧速超 vMax） |

这对应真实海军的"纵队转弯"vs"横队转弯"，也对应银英里的"舰队回转"战术。

### 4.2 拖刀（retreat while engaging）

物理：舰首朝敌（保持火力）+ 质心后退 ⇒ 需要**反向推力**。
刚体模型天然支持：推力方向 ≠ 舰首方向。

## 5. 实施计划

### 阶段 1：新建 `fleetRigid.ts`（纯函数，零 import）

- `RigidState`：x, y, heading, vx, vy, omega
- `stepRigid(state, input, dt)`：推力+力矩积分
- `shipSlot(state, ox, oy)`：刚体公式直算船位
- `omegaCapFor(profile, halfWidth)`：编队约束的角速度上限
- `throttleFor(...)`：推力档位（前进/制动/倒推/停船）

### 阶段 2：台架验证物理量级

`fleetRigidSim.cjs`：
- ω ≤ vMax/halfW（编队不散架）
- 180° 掉头时间与 ω 一致
- 0→95% 速度时间 = 3/accel
- 停船距离 = v²/(2a)
- 外翼弧速 = ω×halfW ≤ vMax
- 拖刀时舰首与位移方向可分离

### 阶段 3：接线（最小侵入）

- `fleet.x/y` 改用 `stepRigid`
- 每舰位置改用 `shipSlot` 公式（删除 `stepShipSlotFollow` 调用）
- `formFacing` / `facingSmooth` / `fAngle` 三量收拢为 `heading`
- `_slotGap` / `maxSlotGap` / `REFORM_SLOT_GAP_PX` / `_slotFlip` 删除
- 保留 `stepShipSlotFollow` 模块（其他调用方可能用），但主路径不走

### 阶段 4：转向模式（紧凑转/松散转）

- AI 按态势选择；玩家可下令
- 紧凑转：先收拢偏移再转

## 6. 风险与规避

| 风险 | 规避 |
|---|---|
| 大编队掉头过慢 | 双模式（紧凑转 2× 速度） |
| 外翼舰被拉开 | `omegaCapFor` 硬约束；超出则警告 |
| 与 AI 决策层耦合断裂 | `getIdealEngageDist` 等接口签名不变 |
| 存档字段变更 | 新字段全部登记瞬态 |
| 退化为"另一堆补丁" | 台架断言物理量级（不是断言代码形态） |
