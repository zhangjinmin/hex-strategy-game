# 战斗全流程重构：舰载机、距离阶段与战术变化（31 号）

日期：2026-10-03。状态：**提案，待裁决**。
前置：`30-space-combat-restructure.md`（运动学与质感）。本文档解决**战斗为什么不好玩**。

## 0. 结论先行

**"对射到死"不是内容不够，是战斗过程中不存在任何迫使双方改变行为的状态转移。**

伤害公式（`BattleScene.ts:7248`）由 **10 个乘区**相乘：

```
baseDmg × damageMultiplier × backstabMulti × cpDmgMult × cpMoraleMult
        × adversityMult × finalMult × moraleDmgMult × retreatFireMul × v33Combo
```

**全部是"谁更强"的标量修正，没有一项是"战况变了"。** 所有乘区都可以在开局前算完 ⇒ 双方从头到尾执行同一条策略 ⇒ 谁 atk 高、谁 typeShare 分摊多，谁就赢。

现存唯一的"变化"来源全是**数值衰减**（补给见底降火力、士气跌降伤害、撤退降火力、阵型崩溃降攻防）。这些让战斗**越来越慢、越来越闷**，但没有让任何一方**改变打法**。

**判定：缺的不是舰载机这一件武器，而是"距离阶段"这个主结构。有阶段，才谈得上变化。**

## 2. 舰载机现状测绘：有名无实

**代码事实**（`BattleScene.ts:7497-7530`）：

```ts
// ===== 航母舰载机系统：突击型舰船环绕母舰的护卫机群 =====
let fighters = this.carrierFighters.get(fleet.id);
if (!fighters) {
    fighters = [];
    for (let i = 0; i < 6; i++) {
        const fDot = this.add.circle(u.sprite.x, u.sprite.y, 1.5, 0x06b6d4)...;
        fighters!.push(fDot);
    }
}
const orbitAngle = time * 0.002 + (i / fighters!.length) * Math.PI * 2;
const orbitR = 18 + Math.sin(time * 0.003 + i) * 3;
```

**判据（逐条）**：

| 维度 | 现状 | 结论 |
|---|---|---|
| 实体类型 | 半径 1.5px 的青色圆点（`Phaser.Arc`） | 不是作战单位 |
| 行为 | `orbitAngle` / `orbitR` 绕母舰画圈 | 无自主行为 |
| 参战 | **零**：不瞄准、不开火、不选目标、不计算命中 | 完全不参与战斗 |
| 生存 | **无 HP**，不可被攻击 | 不存在被击落 |
| 损耗 | 母舰沉没 → 圆点全部 `destroy()` | 唯一的"损失" |
| 真实伤害 | 无 | 无 |

**唯一的"舰载机攻击"**在 `:7285-7300`，且是**另一条路径**：

```ts
if (u.classType === '突击') {
    const fighterCount = 4;
    const dmgPerFighter = finalDmg / fighterCount;   // ← 伤害只是平摊
    pushFx3d({ kind: 'strike', ... });
    for (let i = 0; i < fighterCount; i++) {
        const fighter = this.add.triangle(...);       // ← 纯 tween 动画
        this.tweens.add({ targets: fighter, x: tgtX, y: tgtY, duration: (500+rand*400)/dt, ... });
    }
}
```

这是**"突击舰开火时播一段飞机动画"**，不是舰载机作战。`damage` 就是 `finalDmg/4`，无独立目标、无消耗、无损失、无被拦截可能。

**`gameData.ts:68` 的注释是设计意图的化石证据**：

> 舰载机阵营命名：航母舰载机**不占独立编队槽，随母舰出战，仅显示名不同**。

命名（帝国=王尔古雷 `WK-Ⅱ 女武神`、同盟=斯巴达尼恩 `SP-Ⅲ 斯巴达尼恩`）已经做对，**但行为按"随母舰出战、仅显示名不同"实现** ⇒ 名字对了，机制是装饰。

**编成占比**：`carriers: 5%, fighters: 5%`（`BattleSetupPanel.vue:301`）⇒ 5% 的编制花在了一个不参与战斗的舰种上。

**已存在的可复用资产**（好消息）：
- `pushFx3d({kind:'strike'})` 事件桥已通（`battle3dFx.ts`）
- 3D 舰载机小队模型 + "飞行→格斗→击落→返航"动画（`:7288` 注释）
- `FIGHTER_NAMES` 阵营命名
- `economy.ts` 有 fighter 的成本/维护/收入（`fighter: 30 / 0.1 / 50`）

⇒ **§3 是"把已有壳子填成真的"，不是从零新建。**

## 3. 舰载机波次（核心缺失机制）

### 3.1 原作口径（已查证）

| 设定 | 内容 | 出处 |
|---|---|---|
| **放飞时机** | 「到**最接近战圈前线**时出动」，不是全程跟随母舰 | 同盟航母设定 |
| **放飞方式** | 「脱离的那一瞬间，**只要随着惯性走，便能达到比母舰更快的速度**，根本不需要滑行路段或射出装置」 | 黎明篇·法伦海特 |
| **定位** | 王尔古雷「机型小巧，**火力虽较弱，但活动性强**，最适合近距离肉博战」 | 黎明篇 |
| **对比** | 斯巴达尼恩「战斗能力毫不逊色」，在**攻击力上微胜**，但体积大、续航更好 | 军备大比拼 |
| **回收** | 底部雷射侦测器接收与母舰距离，母舰诱导系统**自动完成著舰** | 同盟航母设定 |
| **不对称** | 同盟航母舰载机停放密集、**舰体下方防御力极差** ⇒ 王尔古雷穿甲后在其下方盘旋可引发**连锁爆炸**（中岛海战） | 军备大比拼 |
| **出击差异** | 帝国航母两侧舱门划出（慢但安全）；同盟垂直起降（快但脆弱） | 军备大比拼 |
| **母舰也有炮** | 「对于一艘以舰载机为主要战力的军舰而言，帝国军的航母**并没有放弃炮击的能力**，这一点在同盟方面也是一样」 | 同盟与帝国的航空母舰 |
| **量产规模** | 帝国宇宙母舰可释放 **12 万**架；同盟仅 **10 万**架 | 军备大比拼 |

### 3.2 差距清单

| 原作机制 | 当前实现 | 差距 |
|---|---|---|
| 接近战圈时放飞波次 | ❌ 不存在 | **最大差距** |
| 脱离瞬间继承母舰惯性、速度反超母舰 | ❌ 不存在 | 决定了"突进"的战术价值 |
| 独立编队、独立目标、独立生存 | ❌ 6 个圆点 | 全缺 |
| 击落损失（可改变战局） | ❌ 无 HP | 全缺 |
| 返航回收 | ❌ 无 | 全缺 |
| 拦截/被拦截 | ❌ 无 | 全缺 |
| 航母下方防御差 → 连锁爆炸 | ❌ 无 | 全缺 |
| 母舰保留炮击 | ✅ 空母 atk 15 / range 880 | 已有 |

### 3.3 设计：舰载机波次

**触发**：舰队进入 **突进阶段**（见 §4）且含 `空母`/`突击` 舰种。

```
放飞（launch）
  ├─ 母舰进入突进航路（朝向敌舰队最佳接近点）
  ├─ 每母舰按搭载量 N 释放 N 架（分 2~3 批，间隔 1.5s，不是齐投）
  ├─ 继承母舰速度矢量 + 突进加成 ⇒ 相对速度 > 母舰
  └─ 编成独立 fighterGroup（有自己的 commander 语义与 AI）

格斗（engage）
  ├─ 目标优先级：敌方舰载机 > 敌舰炮塔位> 敌舰本体（见 3.4）
  ├─ 不可攻击运输舰（原作：攻击运输舰是"非骑士"行为）—— 但可护航
  ├─ 交战规则：单机对单机 1:1，同时 4v4 的消灭率衰减
  └─ 击落率取决于双方数量比 + 舰载机对数（1.41× 身长优势）

脱离（withdraw）
  ├─ 数量比降至 0.6 以下，或母舰脱离接触，或损失 > 50%
  └─ 返航（return）：飞回母舰，母舰存在时可补充损失

空袭（strike）—— 唯一有伤害的时机
  └─ 只有「脱离接触后返航途中」或「突进穿过后拉起」才造成伤害
     （对应原作：脱离瞬间靠惯性冲过敌阵）
```

**关键设计决策：`fighterGroup` 不占编队槽、不参与阵型、不可被玩家直接指挥**（对齐原作"自动著舰"）。但它**有自己的 AI 与生命值**，且**玩家能通过母舰的"放飞时机"间接控制**——这是玩家可感的战术层。

### 3.4 舰载机 vs 母舰的攻防关系（这是"变化"的关键）

原作明确：**舰载机的主要战力是"打瘫单舰"，而母舰的价值在"搭载量 + 自身火力 + 位置"**。

| 目标 | 舰载机攻击效率 | 设计意图 |
|---|---|---|
| 敌方**舰载机** | ★★★★★ 1:1 交换 | 制空权争夺 |
| 敌方**炮舰/战舰** | ★★★☆ 打装甲薄弱处 | 削弱火力节点 |
| 敌方**航母** | ★★☆☆☆ **专打下方（弱点）** | 连锁爆炸 |
| 敌方**运输舰** | ✗ **禁止攻击** | 骑士精神；改为护航 |

⇒ **玩家/AI 的战术选择浮现了**：
1. 突进时先放舰载机 → 换掉敌方舰载机 → 再炮击（制空权是前置条件）
2. 或者先炮击打瘫敌方防空/炮舰 → 降低舰载机遭遇损失
3. 或者抢先打敌方航母 → 连锁爆炸 → 敌方失去后续波次
4. 或者贴近保护己方航母 → 防止敌方王尔古雷穿甲

**这四条路径的收益与风险完全不同 = 变化。**

### 3.5 连锁爆炸（战场事件）

```ts
// 航母舰体下方为弱点，舰载机命中该区 → 连锁爆炸
if (targetShip.classType === '空母' && hitZone === 'ventral') {
    explode(carrier)                    // 航母沉没
    for (adjacent in radius 120) {      // 半径内己方舰载机
        adjacent.hp = 0                 // 全灭（同盟航母的经典死法）
    }
    for (adjacent in radius 80) {       // 半径内友舰
        adjacent.hp *= 0.7;             // 冲击波损伤
    }
}
```

**这是唯一"大舰沉没改变局部战局"的机制**，也是让战斗**产生事件感**的关键。

## 4. 距离阶段（主结构）

### 4.1 现状：没有阶段

`aiDirector.idealEngageDistFrom`（`:204-210`）返回 **540~880px 单一值**。所有舰队都收敛到这个距离然后对射。

地图跨度：射程 300~880px，理想交战距 540~880px ⇒ **双方几乎一开局就进入射程**，没有"接近过程"。

### 4.2 目标：四阶段

| 阶段 | 距离 | 形态 | 主要行为 | 结束条件 |
|---|---|---|---|---|
| **S1 远距对射** | > 1000px | 纵列 / 楔形 | 战列/巡洋齐射，**最大射程决定一切** | 任一方进入 1000px |
| **S2 接近** | 400~1000px | 展开线 / 楔形 | 舰载机放飞、试探性开火、试探侧翼 | 进入 400px 或超时 60s |
| **S3 突进** | 100~400px | **集火纵队 / 单纵阵** | 集中火力打瘫单舰，舰载机穿甲突击 | 目标打瘫/击沉 或 超时 45s |
| **S4 混战/脱离** | < 100px 或已损失 40% | 各自机动 | 近距混乱、脱离、撤退 | 一方全灭/撤退/超时 |

**每个阶段的最优阵型与武器不同** ⇒ 这就是"战术层面的变化"。

### 4.3 阶段转换必须是"有代价的"

这是防退化的关键：**转换本身有成本**，否则 AI 会瞬间跳到最优阶段。

| 转换 | 成本 |
|---|---|
| S1→S2 | 无（自然推进） |
| S2→S3 | 阵型从展开线收成集火纵队 ⇒ **各舰需转向到新槽位**（阶段 2 运动学后 8~15s） |
| S3 内部 | 每次"换目标"需重新对准 ⇒ 炮塔转过去的时间 |
| 任意→S4 | 无强制，但**脱离时转向受限**（这才是撤退的真实代价） |

### 4.4 阶段与玩家的关系

**玩家必须能读懂当前阶段**，且能施加影响：

- HUD 顶部显示阶段条：`远距对射 ──── 接近 ──── 突进 ──── 混战`
- 阶段转换时**广播战报**：「敌方进入突进阶段」「我方放飞舰载机 6 架」
- 玩家指令在阶段间有不同语义：
  - S1 "全速接近" 有效（抢 S2 主动）
  - S3 "全速接近" **无效甚至有害**（会乱阵型）→ 需提示
  - 玩家可直接下令"放飞舰载机"（有冷却）

## 5. 火力集中 / 分割炮击

### 5.1 原作地位

银英的核心战术不是"对轰"，而是**分割炮击**（分批集中火力逐舰击破）。原作战斗描写中，击沉一艘 660 人的主力舰往往靠一次齐射。

### 5.2 当前：无差别伤害

`fireCoordinator.buildFocusTable`（40 行）+ `clusterAI.pickShip`（89 行）已有"集火表"，但：

- 集火表 TTL 1000ms，`FOCUS_TABLE_SIZE = 3` ⇒ **同时 3 个目标**
- `pickShip` 评分 = `hpPct×300 + dps×4 − dist×0.25 + focusRank + attacker×120`
- **效果是"3 个目标各吃约 1/3 伤害"** ⇒ 仍然无差别

### 5.3 设计：单点击瘫（crippling）

```ts
// 同一目标的集中伤害在 T 窗口内累积，超过阈值则产生"击瘫"
crippleAccum[targetUid] += dmg
if (crippleAccum[targetUid] >= 0.35 * maxHp) {
    targetShip.crippled = true
    targetShip.speedMul  *= 0.55      // 引擎受损
    targetShip.turnMul   *= 0.55      // 舵机受损
    targetShip.fireMul   *= 0.6       // 火控受损
    → HUD 打出「CRIPPLING」标记
}
```

**这让"打哪一艘"成为真正的决策**：
- 打脆的（一击就瘫）→ 快速减少敌方 DPs
- 打厚的 → 需要更长集中，但收益更高
- 分散打 → 全部打不死，效率最低

**配合 1% 保底伤害的废除**（见 30 号文档 §5.5），"分散打"会真的更差。

## 6. 战场事件（打破确定性）

| 事件 | 触发 | 影响 |
|---|---|---|
| **连锁爆炸** | 航母下方命中 / 运输舰被击毁 | 半径内舰载机全灭，友舰受冲击波 |
| **核融合炉殉爆** | 任一舰 HP 归零 | 半径 60 内友舰受 40% 伤害（原作高频事件） |
| **大舰沉没效应** | 旗舰/战列沉没 | 全舰队士气 -15、该方 `moraleDmgMult` 立即下降 |
| **弹药/装甲临界** | HP < 25% | 护盾涟漪变红、随机部位损伤 |
| **防空压制** | 摧毁敌方防空舰 | 敌方 `interceptMul` 立即变化（已有 `interceptRateOf`，需接上） |
| **补给线切断** | 已有 `SupplyChainSystem` | 但当前只在 `exploring` 分支运行（26 号文档 §1），需全任务接入 |

**这六个事件全部是"非 DPS 路径"**，它们让战斗结果不可纯数值预测。

## 7. 银英质感的战术层：六个"有名字的决策"

给玩家**可命名、可学习、可传授**的战术，这是"好玩"的最终来源。

| # | 战术 | 做法 | 前置条件 |
|---|---|---|---|
| 1 | **超视距炮战** | S1 拉开距离，用最大射程舰（战列880/空母880）先手打瘫 | 有远射程舰 |
| 2 | **分割炮击** | 集火单舰至击瘫，再转向下一艘 | 有足够 DPS 集中 |
| 3 | **制空权争夺** | S2 放飞舰载机，先清敌方舰载机 | 有航母/突击舰 |
| 4 | **突击机反甲** | 舰载机穿甲打击敌方舰船下层 | 敌方舰载机已清 |
| 5 | **链击沉母** | 舰载机打航母下方 → 连锁爆炸 | 敌航母有舰载机护持 |
| 6 | **脱离/再接** | 损失到阈值后主动脱离，重整后再战 | 有机动能力（巡洋/驱逐） |

**AI 也必须会这套**。`taskForce.selectManeuver` 现在只有 7 个战法（frontal/flank/pincer/decoy/raid/screen/hold），**全是"空间分路"，没有"战斗节奏"**。需要新增一层：`combatRhythm`（战斗节奏）——按阶段选择打法。

```ts
// 新增：战斗节奏层（与 taskForce 的空间分路正交）
rhythm: 'snipe'        // S1 远距对射，不接近
      | 'approach'     // S2 谨慎接近，放舰载机
      | 'assault'      // S3 集中打瘫
      | 'brawl'        // S4 混战
      | 'break_contact'// 损失到阈值，脱离重整
```

**8 种提督性格 × 6 种节奏选择 = 行为多样性**（当前 7 战法 × 8 性格全是空间维度，无节奏维度）。

## 8. 阶段划分

### 阶段 A：距离阶段（最小可行，先做这个）

**只做一件事：把"单理想交战距"换成"四阶段状态机"。**

1. 新增 `src/game/combatPhase.ts`（纯函数，零依赖）
2. 输入：双方位置/HP/组成/阶段计时；输出：`{self, foe}` 各自阶段
