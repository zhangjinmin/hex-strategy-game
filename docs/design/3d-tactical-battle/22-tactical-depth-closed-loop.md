## 0. 结论摘要

**一句话**：用户列出的六项诉求不是一个"功能清单"，而是一条**因果链**——而这条链**每一环都断了**，断得最致命的一环恰好是他亲眼看到的那个（撤退）：

```
分兵 / 迂回  →  切断补给  →  士气崩溃  →  撤退失序  →  胜利
   （手段）       （目标）      （中介）      （结果）    （结算）
     ✗ 不接玩法    ✗ 无入口     ✗ 不可见     ✗ 荒谬      ✗ 只看血量
```

**三条最硬的证据**：

| # | 事实 | 锚点 | 后果 |
|:--:|------|------|------|
| **1** | **撤退由"补给度硬阈值"一票触发，与战局完全无关**：`state !== 'retreating' && (stance==='fallback' \|\| currentSupply < 30)` → 强制撤退；且 `retreatSpeedBonus = 3.0`（3 倍速）。**不看是否接战、不看敌我态势、不看战果** | `BattleScene.ts` 撤退进入/退出（锚 `currentSupply < 30` / `currentSupply > 80`，`:4018` / `:4020`）；速度（锚 `const retreatSpeedBonus = isRetreating ? 3.0 : 1.0`，`:4570`） | 交战中补给到点 → **抛下敌人 3 倍速掉头**（用户原话"离谱"）。且 30↔80 的 50 点滞后带使"撤太深、归队太晚、驻留 10–14 秒"成为常态 |
| **2** | **提督军事风格参数表是"零引用死代码"**：`MILITARY_STYLE_PARAMS` 定义了 8 种风格的 `{formation, attackMod, retreatThreshold}`，**全项目（`frontend/src/**`）除定义处外 0 处引用** | 定义 `tagConfig.ts:87-100`；`grep MILITARY_STYLE_PARAMS` 命中仅定义行 | 用户说"个性标签没有用到"——**这是字面事实，不是修辞**。`PRD_人物标签体系…md:145` 明写 `cautious → 兵力 45% 提前撤退`，从未实现 |
| **3** | **士气的触发源只有一个（断粮）**：`supply < 30 → morale −1.5/帧`、`supply ≥ … → morale +1/帧`。**没有"被背刺掉士气""旗舰被击掉士气""友军溃逃连坐""斩链成功掉士气"** | 士气增减 `BattleScene.ts:1558-1574`；消费 `:4561`（速度 ×0.7–1.0）· `:4849`（伤害 ×0.6–1.0） | 士气是"断粮的附带现象"，不是一条可以**主动打**的战线 → "切断补给"失去了战术出口 |

**核心判断（与 15 号"缺通路"互补）**：
> 15 号的病是"机制没接到玩家手上"；**本文的病是"补给被做成了状态开关，而不是资源"**。
> 前者导致"看不懂"，后者导致"看不懂且不合理"。而**根因 2 恰好是根因 1 的解药**——撤退阈值本该由提督个性提供，现在它躺在死代码里。

**推荐路线（明确建议，非并列选项）**：
1. **第一刀必做 = 撤退架构重构**（下 §3）。它是唯一"用户已亲口点名 + 改动面小 + 是其余五项的支点"的一刀。**在它之前，"切断补给"只会变成"强制对手瞬移逃跑"，"迂回"没有意义（对手反正会跑）。**
2. **同批做 = 个性标签接入**（§4.1）。因为撤退阈值就是 `MILITARY_STYLE_PARAMS.retreatThreshold`，两件事共用一处改动。
3. **第二优先 = 士气可见化**（成本最低，立刻把"看不懂"变成"看得懂"）。
4. **之后 = 切断补给玩家化 → 分兵/迂回接线 → 阵型可玩化**（顺序不可颠倒，理由见 §5）。

## 2. 根因诊断

### 根因 1（架构级，最重要）· 补给被做成了"状态开关"，而不是"资源"

当前代码把**补给度**当作**撤退的触发条件**：

```
撤退进入： currentSupply < 30   →  强制 state = 'retreating'
撤退退出： currentSupply > 80   →  state = 'exploring'
撤退速度： retreatSpeedBonus = 3.0
```

这在设计上等价于**给每支舰队挂了一个倒计时炸弹**：时间一到（补给耗尽），无论你在干什么，都必须离场。

**三个直接后果**：
- **A（用户原话）**：交战中补给到点 → 抛下敌人 3 倍速掉头。**没有任何"脱离接触"过渡**——`retreating` 是二元瞬时状态，没有"边打边退"这个中间态。
- **B**：30↔80 的 50 点滞后带（退出线远高于进入线）。`v16_03` 已登记为 P1「占领完原地发呆、敌军路过不动」——因为补给 30→80 要靠运输舰/回基地，恢复到 80 很慢，舰队就在撤退态里**停船重组 10–14 秒**。
- **C**：撤退目标只有「最近补给源 / 原地」，**从不包含"正在赶来的运输舰"**（`v16_03` C.4 已登记为"实现与已拍板设计不一致"）。

> **第一性原理**：补给是**消耗品**，它应该决定「你还能打多久」（战斗力随时间衰减），而不是「你什么时候必须离场」（状态开关）。把"资源"当"状态机"用，是这个系统全部荒谬感的来源。

### 根因 2 · 提督个性 → 战术行为的通路是**零引用死代码**

`MILITARY_STYLE_PARAMS`（`tagConfig.ts:87-100`）：

| 风格标签 | 阵型倾向 | 进攻系数 | **撤退阈值** |
|----------|:----:|:----:|:----:|
| `frontal_assault` 正面突击 | wedge | 1.3 | 兵力 20% |
| `counter_defense` 防守反击 | square | 0.8 | 35% |
| `firepower` 火力压制 | line | 1.1 | 25% |
| `mobile_raid` 机动突袭 | spindle | 1.2 | 30% |
| `logistics_focus` 后勤重视 | circle | 0.9 | 40% |
| `intel_focus` 情报重视 | flexible | 1.0 | 30% |
| `cautious` 谨慎型 | square | 0.7 | **45%** |
| `aggressive` 冒险型 | wedge | 1.4 | **15%** |

**这三个字段是一个完整的"个性 → 战术"映射**：阵型偏好、进攻性、动摇点。
**但全项目 0 处引用。** 用户在 3D 战场上看到的每一支舰队，无论提督是杨威利还是鲁道夫，行为**完全一致**。

> **关键**：`retreatThreshold` 正是**根因 1 的解药**。撤退本就该由"提督何时动摇"（个性）+ 士气决定，而不是由"补给几点耗尽"（时钟）决定。**两件事共用一处改动。**

### 根因 3 · 士气是"三不可"——不可见、不可操作、不可归因

- **不可见**：`morale` 在 `Battle3DOverlay` 命中数为 0。billboard 只有 HP / 补给 / 3 个姿态按钮。
- **不可操作**：触发源只有断粮；恢复手段只有"进入补给圈 +1/帧"。玩家没有任何"督战/鼓舞/稳住"的动作。
- **不可归因**：伤害飘字不标注来源（背刺 / 相克 / 士气 / 护盾），玩家只能看到数字变小。

> 结论：士气现在是**断粮的附带现象**，不是一条独立的战线。**"切断补给"要产生战术价值，必须经由士气这个中介**——否则断粮的直接后果只是"对方撤退"（回到根因 1 的荒谬）。

### 根因 4 · 阵型数值在战术层是死代码 + 不可见 + 无代价

三重折扣：数值不生效（`attackMod` 等只在战略层调用）+ 生效的那部分（相克 ±30%）不可见 + 切换没有代价（`moraleCost` 已定义未用）。⇒ 玩家的"阵型决策"实际上是**盲选且无成本**，不可能产生策略。

### 根因 5 · 分兵 / 迂回：几何已备，玩法未接

`fleetSplitManeuver.ts` 是一个**完整且经过闭式验证**的三幕机动几何（`splitMinClearanceClosedForm` 保证两翼不互穿），但契约第 17–19 行明文写着"不接任何玩法触发"。
⇒ 这是**收益率最高的接线机会**：几何、动画、防互穿都已经解决，只差"什么时候发动 + 发动了有什么收益"。

## 3. 第一刀（P0 地基）· 撤退架构重构

> **目标**：把"补给到点就掉头"改成"**打得下去，但越打越弱；打不下去，才缓慢退**"。
> **改动面**：`BattleScene` 撤退进/出 + 撤退分支目标 + 速度乘区；**不动** `SupplyChainSystem` 的任何参数（该文件已被多轮调参，见 §5 风险）。

### 3.1 规则级设计

| 项 | 现状 | 改为 |
|----|------|------|
| **撤退触发者** | `supply < 30`（时钟） | **士气 + 态势**：`士气 < 该提督的动摇线` 且 `战力比 < 阈值`；**补给不再做触发器** |
| **补给的作用** | 触发撤退 | ① 战斗力乘区（断粮 → 伤害/速度衰减，已有 `supplyFactor` 可扩展）② 士气**衰减速率**（断粮 → 士气持续下滑） |
| **撤退档位** | 单一 `retreating` | **三档**（见下表） |
| **进入过渡** | 瞬时切换（一帧掉头） | **"脱离时间"**：进入任何撤退档需 3–5s 逐步减速 + 转向；交战中**不能**一帧掉头 |
| **动摇线** | 全局 80（兵力除外：`hpPct<0.3`） | **提督个性提供**：`MILITARY_STYLE_PARAMS.retreatThreshold`（谨慎 45% / 冒险 15%） |

### 3.2 三档撤退（这是"缓慢撤退"的实现）

| 档位 | 触发 | 速度 | 火力 | 防御 | 玩家观感 |
|------|------|:----:|:----:|:----:|----------|
| **`disengage` 脱离接触** | 士气 < 该提督动摇线（如 40–60）**且**处于劣势 | ×1.3 | 70% | 100% | **边打边退**，可被追击、可反打 |
| **`withdraw` 撤离** | 士气 < 25 或玩家手动 | ×2.0 | 40% | 80% | 明确后撤，仍有自保 |
| **`rout` 溃散** | 士气 = 0（崩溃） | **×3.0** | 0% | 50% | 真正的"掉头就跑"——**现状的 ×3.0 降级为溃散专用** |

> **关键**：现状的"一帧掉头 ×3 速度"被**降级**为只有"士气彻底崩溃"才会发生。**这是把用户说的"离谱"变成一个"该有的失败状态"。**

### 3.3 验收判据（可量化，供后续独立验证）

1. **不再抛下敌人**：构造"接战中补给降至 29"→ 断言舰队**不会**在 5s 内离开交战半径（`minFleetDist` 不增大）；且断言此时**仍开火**（`isEngaging` 保持）。
2. **缓慢撤退可测**：进入撤退后，航向变化率受"脱离时间"约束——连拍 ≥6 帧，转向角速度 ≤ 门限（可复用 `v14` 撤退朝向探针的做法）。
3. **个性可测**：同一场景、同兵力下，`cautious` 提督在兵力 ~45% 进入 `disengage`，`aggressive` 在 ~15% —— 两者差值可测量。
4. **回归不破**：`SupplyChainSystem` 的"运输舰能把舰队补给度拉回 80"这条既有修复（`:37-49` 注释即其来源）**必须仍成立**（跑既有补给台架）。
5. `tsc` EXIT=0。

## 4. 后续四刀（按依赖顺序，不可颠倒）

### 4.1 第二刀（与第一刀同批）· 个性标签接入战术层

- **接入 `MILITARY_STYLE_PARAMS`**：`formation` → 该提督的默认阵型（AI 每次接敌不再随机覆盖）；`attackMod` → 推进/交火阈值；`retreatThreshold` → 第一刀的动摇线。
- **同时接入人格标签的战术含义**（现在只影响投票/忠诚）：例如 `cautious` + `logistics_focus` → 更早后撤、更依赖补给；`aggressive` + `frontal_assault` → 更高推进权重、更低动摇线。
- **玩家可见**：billboard / 详情面板显示"该提督的风格倾向"（如"谨慎 · 动摇线 45%"），让玩家**能预判**。

### 4.2 第三刀 · 士气可玩化（成本最低，优先级高）

- **可见**：billboard 增 0–100 士气条（与 HP/补给并列）。
- **触发源扩展**：断粮（已有）/ 被背刺 / **旗舰被击沉** / **友军溃逃连坐**（邻队士气 −）/ **敌方斩链成功**（我方士气 −）。
- **恢复手段**：督战命令（CP）/ 旗舰舰队邻接 / 击沉敌方旗舰（士气跃升）。
- **作用**：士气低 → 接战意愿下降 + 命中下降 → **这就是"切断补给"的战术出口**（不打光你，让你自己崩）。

### 4.3 第四刀 · 切断补给玩家化（闭环的目标）

- **入口**：新增 mission `raid_supply`（猎杀敌方运输舰）/ `escort_supply`（护航己方运输舰）。运输舰当前是 `unit` 不是 `fleet`，目标解析需支持 aux（**现有 `attack_fleet` 选不中它**）。
- **奖励**：斩链成功 → 敌方**全体**士气 −30 且 20s 内不自动受补；我方 CP +2；横幅提示。**这让"破网→斩链→拔旗"从装饰变成可兑现的目标。**
- **风险**：`SupplyChainSystem` 已被多轮调参（v3 / v6.1），**任何打分函数改动都必须先跑回归台架**。

### 4.4 第五刀 · 分兵 / 迂回接线（闭环的手段）

- **接线**：`fleetSplitManeuver` 的三幕几何接一个"包抄"任务（玩家可发起，或 AI 按 `role` 发起）。
- **precondition**：**必须先定义收益**——建议 = ① 侧翼/背刺加成（`backstabMulti` 已存在，1.5×）② **切断敌方退路**（与第三刀联动：把敌方压向不利方向）。
- **风险**：实时制下新增输入会打断节奏 → 建议走"选中舰队 → 一个指令"的单次操作，**不要开暂停面板**。

### 4.5 第六刀 · 阵型可玩化

- **先做**：相克**常态可见**（billboard 一个 2 字标记：`克`/`被克`/`—`），并把 UI 里**当前不成立**的描述（"铁壁防御"等）先改掉——**信息真实优先于数值平衡**。
- **再做**：`attackMod/defenseMod/speedMod` 接入战术层 + 切换代价 = `moraleCost`（已定义未用）。
