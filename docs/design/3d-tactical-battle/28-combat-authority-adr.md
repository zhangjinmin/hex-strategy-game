# 28 · 战术战斗权威链 ADR

**状态：采用**  
**日期：2026-09-22**

## 问题

战斗中曾把“聚合战斗实体是否死亡”直接当成“3D 模型是否该存在”的唯一条件。每个实体代表多艘舰，随机伤害会把 HP 均匀摊到所有实体：舰队血条已跌到约三分之一，而每一个实体都仍有少量 HP，于是完整舰阵仍被渲染。反过来，不能为了让模型变少而删除这些尚未死亡的实体，否则会把视觉需求错误地变成额外战损。

信标也曾根据落点距离猜测收件舰队，导致一条给指定舰队的玩家命令可能改变其他友军航向。

## 决定

建立以下单向数据流：

```
CombatState (HP / 攻击 / 补给 / 战后兵力)
      ├─ TacticalDirector (目标、航向、阵型承诺)
      └─ CombatRepresentation (模型、光点、标签的可视战损投影)
```

- `CombatState` 是唯一数值权威。只有它能扣 HP、判定实体阵亡、写回战役兵力。
- `CombatRepresentation.projectFleetRepresentation` 从全舰队 HP 生成稳定的可见模型集合；同一 HP 状态的选择固定，不允许逐帧随机闪烁。
- 模型被投影层隐藏不代表战斗实体死亡；其火力、受击和战后残余仍以 `CombatState` 为准。
- 玩家信标必须有已选中的玩家舰队收件人。没有收件人时拒绝命令，不允许按距离猜测。
- 交战中的阵型是一次“战术承诺”：首次接敌、换目标、脱离接触或紧急撤离才可重新计划。

## 权衡

该方案让低血量舰队的画面与血条一致，同时不改变既有 HP 守恒和战后结算。代价是个别隐藏模型仍可能贡献聚合火力；这是有意保留的，因为每个模型本来就代表一组舰艇，而不是一艘独立、可单独结算的船。

后续若需要逐舰损管或逐舰火力熄灭，应把聚合实体进一步拆成“战斗编组 + 渲染代表”，而不是在 3D 覆盖层删除数据。
