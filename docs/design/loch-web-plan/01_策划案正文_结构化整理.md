## 1. 项目定位

### 1.1 引子 / 背景 / 设计思路

> 来源：图 `d50735…ef4`（策划案首页）

- **引子**："我们想要制作的可能并不是一款完美的游戏，但是却是一款能与我们有共同语言的朋友们一起享受的游戏。"
- **背景**：《银河英雄传说》为田中芳树代表作，获日本 SF 小说最高奖"星云赏"长篇作品奖；已改编动画、漫画、游戏、真人舞台剧。2004 年曾有银英 ONLINE 化机会，因不可预期因素未真正实现。本作即为此遗憾的补完。**（案中自述：韩方 GAME ON 株式会社于 2010-04-26 取得银英 WEB 游戏开发权，2012 年 3 月未完成第一次测试。）**
- **设计思路**（原案自述）：
  - 模拟国家间阵营对抗的 **SLG** 类型；
  - 玩家扮演不同势力、不同职位的人物，通过**内政、谍报、军事**等方面努力，实现己方势力最终胜利；
  - 以系列最经典的 **4EX 为蓝本**，融合 **银英 ONLINE、太阁立志传、文明、GNO** 等游戏的特色；
  - **背景可替换**（换掉银英背景可成为其他换皮游戏）；
  - 采用**轮回模式**：一轮结束后总结玩家经历并保留基础数据，重新进入新一轮循环。

### 1.2 核心循环：轮回（Round）

> 来源：图 `e850352a…`

- **游戏有效时间**：宇宙历 **795 年 1 月**（第 3 次迪亚玛特会战）→ 宇宙历 **801 年 8 月 1 日**。约 6 年 7 个月。
- **一轮结束后**：统计玩家游戏经历 + 所属阵营胜负关系 → 给予**功绩 / 活跃度 / 影响力**评价奖励；完整参与者另给**功勋章**奖励；保留人物数据 → 开始新一轮。
- **终战评价**内容清单：
  1. 人物的最终基础能力；
  2. 累计执行**指令**数量与成功率；
  3. 累计执行**提案**数量与成功率；
  4. 累计取得的活跃度功绩与影响力、消费的影响力；
  5. 参加战役次数与负伤情况；
  6. 最终所属势力、最终职务、官阶、受勋、受爵情况；
  7. 最后给出**个性化评语总结**。

### 1.3 游戏目的与胜负条件

> 来源：图 `871836…b27`

- **游戏目的**：银英传 WEB 让玩家重新进入那个遥远未来英雄辈出的年代，扮演心目中的英雄；与战友经历波澜壮阔的时刻，以自己的智慧与力量创造属于自己的银河历史。
- **玩法定位**：扮演银河帝国与自由行星同盟中的各级官员，以击破对方势力为最终目的。人脉与能力最终成为改变国家命运的关键。可经**政治、经济、军事、谍报**等方式参与。

| 名称 | 达成条件 | 声望奖励比例 |
|---|---|---|
| 完全胜利 | 完全占领对方所有星系，并消灭对方所有主力舰队 | 200% |
| 普通胜利 | 占领对方主星，迫使对方势力最高领导签订投降协议 | 150% |
| 判定胜利 | 在领地、舰队数量、活跃玩家数超过对方 50% 以上的 | 120% |
| 特别胜利 | 在战场直接消灭对方最高领导人 | 120% |
| 特别败北 | 势力长期还处于内乱状态；无法支付各项经费超过 6 个月，导致国家财政破产；国家最高领导人因意外死亡（遇刺） | 50% |
| 特别平手 | 双方最高领导人达成和平协议 | 100% |
| 败北 | 对方达成胜利条件 | 75% |
| 判定平手 | 双方势力在有限时限内，都不能达成以上条件的，判定平手 | 90% |

## 3. 角色系统

### 3.1 登录与人物创建流程

> 来源：图 `0b46f21f…`

```
登录 / 服务器选择
   ├─ 人物创建 ──→ 基本信息 ──→ 阵营立场 ──→ 性格诊断（多选） ──┐
   ├─ 人物选择（管理）──→ 进入游戏 ←───────────────────────────┘（确认）
   │        │
   │        ├─ 剧情介绍 ──→ 自宅 / 个人舱
   │        └─ 新手教程（军校）
   └─ 基本信息 / 国力比（星球）/ 原著人物 ──→ 进入游戏
```

- **游戏登陆（图 `37d3d539…682`）**：主界面含 ID、PW 输入与服务器选择界面，背景为银英主体大幅；进入后**人物画面**显示：姓名、所属势力、能力、影响力、攻击、所处位置与状态；可执行人物新建、删除、隐居。
- **账号规则**：一个账号只能建立一个角色；**连续 2 周（现实时间）处于低活跃状态自动冻结账号**，使角色不在游戏内出现以节省系统资源；冻结后可重新激活，在指定位置（主星）以平常状态复活。

### 3.2 人物创建

> 来源：图 `37d3d539…682` + `cdbf6c81…`

1. 回答 **5~7 题**性格测试；
2. 根据性格、年龄、出身决定**基础能力**（可以随机微调）；
3. 可自由调整**各型点**（根据出身和账号功绩累计决定）；
4. 最后决定姓名与出身份（所属势力）；
5. 新一轮游戏开始时可继续使用旧人物，也可对出身份（所属势力）加以选择。

**创建界面分区**（图 `cdbf6c81…`）：左栏 = 头像/所属 + 八项能力 + 特技 1/2/3 + 总功绩/晋升必要影响力；右上 = 头像选择 + 势力基本信息修改 + 确认/修改；右下 = **能力诊断** + 确认/修改。

**公式**（图 `42a98226…` 与 `37d3d539…684`）：

```
原始能力 + 自然成长 + 手动成长 = 基础能力
基础能力 + 修正能力 = 实际能力
修正来源：军衔修正、职务修正、奖章修正、副官修正
```

#### 3.10.1 特技规则（原案）

- 特技属于个人的特殊能力，在**战略和战术阶段**都可以起到特别的辅助效果，也是人物特色的标志之一。

- 特技设定基本规则：**个人最多持有 3 项特技**，**战略阶段副官的特技可以叠加和修正官的能力**。

### 3.11 玩家三阶段与三条职业路线

> 来源：图 `b8389b50…`

- **第一·新人阶段**：第一轮参加游戏新进入游戏的玩家。能力和地位都比较低下，且与其他玩家不熟。可通过**先在军官学校学习完成新手任务**来集中锻炼某项基础能力，决定以后发展的方向。文官方向玩家在能力得到提高后，前任人员比较稀少的后方官系，执行生产开发加速类的**指令**，积累功绩点和活跃度，并结识其他玩家以扩大自己的影响力。武官方向玩家需要有**一定的人脉关系**，能被直接编入舰队，担任副官等职务，可以直接进入战场享受功绩分配或执行相关军事指令积累功绩。
- **第二·普通玩家阶段**：经过了一轮游戏，对游戏流程和基本操作都有了相当的了解，并申请到了一定职位的玩家，也是多数玩家处于的状态。可以根据自己的喜好和能力育成的方向当然适当的职务，行使职务的权限参与，参与到具体的内容，还可以通过执行**提案**和联名提案等方式对游戏内容实施影响。
- **第三·高端玩家阶段**：并不是所有玩家都可以达到的阶段；担任势力的要职的玩家，关系到游戏中势力的命运，还可以在势力内**组建自己的派系**，甚至成为势力内的独裁者，直接领导其他玩家实现胜利目标。不过相对也会占用更多的精力和时间投入游戏才有可能实现。

## 4. 核心机制：提案驱动

> 来源：图 `32fa828b…`（普通）、`cefc1e17…`（联名）、`d0c8a786…`（悬赏）、`024f78f0…`（职务任务）、`14ce36d3…`（轮次累积）、`dc54564e…def`（功绩审核/生产）

### 4.1 普通提案

**定义**：由个人提出的、**由其他人执行**的提案。内容包括：具体的执行人、执行的指令内容和执行的具体时间段。是最基本的提案方式。

**判定逻辑**：
1. 提交后系统根据**提案具体执行人和提案人的功绩**、**提案执行难度**，给出**成功率**和**强制通过所需要消费的影响力**；
2. 提案成功 → 由执行人执行；
3. 提案不成功 → 可以**通过消费影响力强制通过**，给予执行人执行；
4. 执行阶段**执行人有权在时限内选择执行或驳回**；驳回同样可消费影响力；
5. 如果没有驳回，在时间限制最后阶段会**强制执行**，而执行人功绩奖励将被削减；
6. 此外在**执行阶段，最高领导人可以直接驳回任何提案**。

```
累计行动力 → 提案 → 判定通过 → 执行 → 效果
              │        │          ↑
              │        │      消费影响力强制驳回（最高领导人）
              ↓        ↓
          判定未通过 → 消费影响力强制通过
                         执行阶段：特殊强制驳回
```

### 4.2 联名提案

**定义**：由**提案人发起，并与支持此提案的人联名**提出的提案。内容同样包括具体执行人、指令内容、执行时间段。

**判定逻辑**：
1. 提案发起后，系统根据提案具体执行人的功绩和提案执行难度，给出执行此提案必要的**联名人数**和**总功绩数**，并给出**联名的限制时间**；
2. 只要在**限时内达到联名要求**，就可以直接提交给执行人执行；
3. **执行人不能直接驳回联名提案**，只能**征集联名人联名驳回**；
4. 如果超过驳回的联名时间则强制执行，而执行人功绩奖励将被削减；
5. 在**执行阶段，最高领导人可以直接驳回任何提案**。

```
累计行动力 → 联名提案发起 → 联名累计 → 执行 → 效果
                    ↑            │        ↑
                    │            ↓    联名驳回
                 联名超时      联名驳回 →（联名驳回成功则回到累计）
                                特殊强制驳回
```

### 4.3 悬赏提案

**定义**：由**提案人发起悬赏，并在执行完成后提案人直接支付额外奖励**的提案。内容包括：执行指令的人数、执行指令内容和执行的具体时间段，还有**额外悬赏的奖励**和**给予奖励的比例**。

**判定逻辑**：
1. 提案发起后，系统会**给出悬赏的时间**；
2. 在有效时间内有符合条件的人**应募**，就可以执行悬赏提案，并根据完成效果**兑现悬赏**；
3. 如果超过悬赏时间**没有人应募**则**自动取消**，不消费额外悬赏；
4. 在**执行阶段，最高领导人可以直接驳回任何提案**。

```
累计行动力 → 悬赏发起 → 悬赏募集 → 执行 → 悬赏兑现
                    ↑        │        ↑
                    │        ↓    特殊强制驳回
                 超时撤销 ─────┘
```

### 6.1 战术模式流程

> 来源：图 `58ee3d6d…`

```
舰队星系侵入 ──→ 舰队战 ──┬─→ 登陆战 → 全球制压 ──┬─→ 残余舰队扫荡 → 攻击侧获胜 → 终战统计

                          │                        └─→ 制压失败 → 攻击侧撤退
```

**阶段语义**：舰队战（制宇权）→ 登陆战（行星地表）→ 全球制压（守备）→ 残余舰队扫荡（清剿）。**四阶段串联，避免"打赢舰队 = 直接占领星球"的跳跃。**
