## 一、模型命名规则（关键）

3D 旗舰模型放在 `frontend/src/assets/ship/`，文件名格式：

```
flagship_{key}.glb
```

登记位置：`frontend/src/game/three/Battle3DOverlay.ts:52` 的 `FLAGSHIP_MODEL_ALIAS`

```typescript
const FLAGSHIP_MODEL_ALIAS: Record<string, string> = {
  '伯伦希尔': 'brunhild',   // 莱因哈特
  '休伯利安': 'hyperion',   // 杨威利
  // '盘古': 'pangu', '王虎': 'wanghu', '火龙': 'huolong', …按需登记
};
```

**加载回退顺序**（`Battle3DOverlay.ts:1156-1162`）：
`flagship_{key}.glb`（专属）→ `{faction}_{class}.glb`（阵营+舰种）→ `{class}.glb`（通用舰种）

## 四、需要注意的几点

1. **「艾亚斯」重名**：库布斯里（同盟中将）与罗波斯（同盟元帅）的旗舰都叫「艾亚斯」。做模型时要决定是共用同一个 `ajax.glb`，还是拆成 `ajax_kubusly` / `ajax_lobos`。
2. **「雷欧达」与「雷欧达II」**：培特雷与鲁格拉希的旗舰是同名系列，建议 `leodas` / `leodas2` 区分。
3. **「诺德林根/西瓦」**：梅尔卡兹的旗舰名含斜杠（在游戏中期更换过），建议取前半段 `nordlingen`。
4. **2D 贴图只有 2 个旗舰**（brunhild/hyperion.png），其余 50 艘在 2D 模式用阵营通用舰船图（`empire_ship` / `alliance_ship`）。
5. **无专属旗舰的 131 名提督**：`flagshipName` 为空，2D 用阵营通用图，3D 走 `{faction}_{class}.glb` 回退。

## 五、3D 建模注意事项

- **舰首朝向**：Blender 导出的 glTF 舰首朝 +Z，但战场约定舰首 -Z，代码已默认统一翻转 180°（`SHIP_MODEL_DEFAULT_BOW_FLIP = true`，`Battle3DOverlay.ts:58`）。若某艘模型本来就朝前，在 `SHIP_MODEL_NO_FLIP` 登记豁免。
- **尺寸基准**：战列舰长度基准见 `Battle3DOverlay.ts` 顶部注释（战列舰长=0…），建模时按比例来。
