# v85 到达制动律（修移动振荡）+ 尾焰粒子随 LOD 淡出

日期：2026-10-15。用户实报两个问题：
> ① 移动时会出现诡异的**振荡、摆动**，舰船在没有任何接敌时出现**倒着飞、各种乱晃**
> ② 敌方仍出现**粒子和模型同框**（红色粒子是舰船，金色是尾焰）；**放大之后只有尾焰还在**

---

## 问题①：v73 的推力积分**遗漏了制动律**

### 仿真复现

| 项 | 值 |
|---|---|
| 推力加速度 `a` | 0.00042（战列） |
| 巡航速度 `v` | 0.22 |
| **停船距离 `v²/(2a)`** | **≈ 57.6px** |

**旧行为**：舰队以满速冲向目标，**冲过 57.6px 才开始反向** ⇒ 目标跑到身后 ⇒
掉头 ⇒ 又冲过 ⇒ **极限环振荡**（用户读作"倒着飞 + 乱晃"）。

**根因**：v73 只做了"推力有限性"（起步慢、有惯性），**没做"该在何时减速"**。
两者是同一个物理模型的两半，缺一半就是**欠阻尼控制回路**。

### 修复：到达制动律（Arrive）

```ts
const _vAllow = Math.sqrt(2 * kinAccel * Math.max(0, distToTarget));
if (_tm > _vAllow && _tm > 1e-9) { const _k = _vAllow / _tm; _tgtVX *= _k; _tgtVY *= _k; }
```

- 远距离 ⇒ 上限大（不干预）
- 临近 ⇒ 平滑降速 ⇒ **恰好能在目标前停住**

配套：`dvCap = kinAccel * Math.max(1, _level) * dt`
（**刹车能力不得随档位缩水** —— 旧式 `level` 在 <1 时会让减速极慢）。

### 仿真验证

| | 超调 | 结果 |
|---|---|---|
| 修复前 | **57px** | 冲过 → 反向 → 振荡 |
| **修复后** | **0.1px** | 平滑收敛（2794 帧） |

## 问题②：v83 遗漏了 `flamePoints`（尾焰粒子）

v83 修了 `glow` / `flame` **锥**（挂在实体 `group` 下）随 `grow` 淡出，
**但 `flamePoints` 是独立的全局 `Points` 系统**（不挂 group）⇒ 实体被 LOD 隐去后
**粒子仍照常发射** ⇒ 「只有尾焰没有舰船」「粒子与模型同框」。

### 修复

```ts
for (const [flameKey, entry] of this.ships) {
  const _uv = this.unitVis.get(flameKey);
  const _grow = _uv ? _uv.grow : 1;
  ...
  aAlpha[i] = (1 - k) * (1 - k) * 0.55 * _grow;   // ×grow
}
```

⇒ 尾焰粒子与舰体可见性**同步**。

### 教训

**v83 的"同类问题排查"不彻底**：当时只检查了挂在 `group` 下的网格，
**没有穷举所有"面片/粒子类**特效**"。正确做法是：列出全部 `THREE.Points` 与
`AdditiveBlending` 材质，逐个确认是否随 `grow` 淡出。
