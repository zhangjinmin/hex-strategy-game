# v28 · 喷口形状改为「从锚点向外扫描撞墙」—— 独立验证报告

> 日期：2026-09-17 ~ 09-18　批次：v28 / v28c / v28d / v28e（喷口形状真源 → 尺寸闸门 → 柔晕穿模 → 扫描形状闸门）
> 结论：**已修复** —— `_fx_scan` 26/26、`_fx_glow` 8/8、`_fx_spike` 0 异常口，另有 3 套既有回归全绿、`vue-tsc` EXIT=0。

## 1. 用户诉求（原话）

> 「现在的喷气口尾焰，我用 blender 做了空物体，但**我不想要设置默认的 x 直径**，因为有很多战舰，
> 我需要的是你按照我给出的点，然后**向外扩散到撞到模型内框**……我给你定了位置，然后你**负责扫描内框处形状**，
> 因为喷气口的形状不光是圆和方，还有很多**异形**的。」

判读：v27 的锚点约定把"半径"（空物体缩放 X）当成**必填**，于是每一口都要作者手工量、还要记得改缩放
—— 实测已发生事故（`alliance_battleship.glb` 两个锚点半径差 **333 倍**：0.5 舰长 vs 0.0015 舰长）。
本批把**半径降为可选**，形状与尺寸改由程序从几何现场量出。

## 2. 语义变更（对照表）

| 项 | v27（旧） | v28（本批） |
|---|---|---|
| 锚点"半径"（缩放 X） | **必填**，= 光斑半径 | **不用给**；仅 `round`/`rect` 两档需要；`scan` 档只当"最远找多远"的搜索上限 |
| 半径异常值（0.5 / 0.0015 舰长） | 照单全收 ⇒ 一个糊住半条舰、一个看不见 | **只采信舰长的 0.4%~12%**，超出即忽略并走扫描 |
| 形状来源 | 圆盘 / 方片 / 外轮廓 / 内框线（都是"猜哪块是开口"） | 默认**扫描切平面内的内壁**：圆/方/椭圆/六棱/异形**一律不分派** |
| 切哪一刀 | —— | 从锚点沿 **+Z（朝外）逐档推进**，取"仍被内壁围住"的最大截面（= 口沿那一圈）|
| 键位 | `ENGINE_PORT_OPTS.mode ∈ {convex, inner}` | 增 `scan`（**默认**）；巡览面板加第 3 颗「扫描内框」 |

## 3. 实现（唯一真源 `frontend/src/game/three/battleFx.ts`）

- 新增 **`scanPortOpening(geo, modelLen, mark, q?, searchR?, opts?)`**：
  以锚点为原点、锚点局部 **+Z 为法线切一刀**，在**切平面内**打 **96 条射线**，取每条射线打到模型表面的
  **最近交点**半径 r(θ) ⇒ 连成闭合多边形（归一化、以锚点为原点）⇒ 直接喂 `ExtrudeGeometry`。
- 新增读数 `EnginePort.scan`（`hitRate / rMed / depth / rmax / tri / seg`），巡览面板直接显示
  「🔎 扫描命中 xx% · 中位半径 x.xx% 舰长 · 切割深度 …」。
- 解析优先级不变（锚点 > 手点标注 > `ENGINE_PORT_STYLE` > 自动探测）；锚点内部：作者明写
  `round`/`rect` ⇒ 以作者为准；巡览选 `convex`/`inner` ⇒ 走 v25/v26 栅格化；否则 **扫描**。

### 3.1 算法要点（重写时不可丢）

1. 逐顶点预投影 `pU/pV/pN` 三组标量 ⇒ 换切割深度只差一个常数。
2. 三角形 × 切平面 ⇒ **线段**（取最远的一对交点）；再与射线做 2D 射线-线段求交：
   `den = cross(d,v)`；`s = cross(A,v)/den`；`t = cross(A,d)/den`（`s>0` 且 `t∈[0,1]`，逐射线取 min）。
3. **与切平面共面的三角形不挡光**（射线在平面内 ⇒ 物理上就是掠过）。没有这条，把点压在平尾板上
   会描出三角网格的"蜘蛛网"。
4. 缺口 ⇒ 沿口沿外推（两侧最近有效射线取大者）；尖刺 ⇒ 中位数倍率 `2.2` 夹；
   合理性闸门 ⇒ 中位半径 ≤ 舰长 `18%`，否则弃用退回圆盘。
5. 朝外扩展的三道防咬闸：超出搜索半径 / 不再被围住（命中率 < 0.35）/ 单档增幅 > `1.6×` /
   总面积 > 第一刀 `2.5×` ⇒ 一律停，用上一档（防切平面跑出口外后咬住"尾板外缘"）。
6. 锚点那一刀完全撞不到墙（点在口沿/口外一点点）⇒ 改沿 −Z 逐档往里找第一档能围住的。

## 5. [v28c] 用户实拍「为什么这么大」—— 根因与修复

### 5.1 现场取证（连**用户正在运行的 dev server** :5173 取真值，非离线台架）

`_fx_repro.cjs` 走真实入口（主菜单 → 战术模拟 → 舰艇模型巡览）读到：

| 口 | 位置 | 扫描命中率 | 中位半径 | **画出来的直径** | FX 几何（两层） |
|---|---|---|---|---|---|
| FX_ENGINE_1 | (−0.0189, 0.058, 0.389) | 1.00 | 1.39% 舰长 | **2.76%** | 1.435×0.891 |
| FX_ENGINE_2 | ( 0.0206, 0.061, 0.394) | **0.76** | 1.89% 舰长 | **5.29%** | 2.014×1.604 |

同一艘舰的两个同类喷口 **直径差 1.92 倍**，且第二口 24% 的方向根本没打到墙 —— 这就是"这么大"。

### 5.2 根因（两处都出在我自己的"容错"上）

1. **缺口补全带方向性偏置**：`[v28]` 用"左右最近有效射线取**较大**者"补没撞到墙的方向
   ⇒ 命中率 0.76 时被撑出大瓣（实测 `outlineMaxAbs` 0.0265 vs 中位 0.0189，**+40%**）。
2. **朝外扩展只要求"命中率 ≥ 0.35"**：于是第二口被推进到一档"**半开放**"的切面
   （`depth=0.0108`，且该档命中率只有 0.76）—— "取仍被围住的最大截面"的前提根本不成立。
3. 另一条制度性缺口：**v24 那四道尺寸保护只作用于自动探测路径，锚点路径此前完全没有上限**
   ⇒ 作者把缩放 X 留在 1（半径 = 0.85 条舰长）时能画出盖住大半条舰的光斑（v27 起的老问题）。

### 5.3 修复（三处，均在 `battleFx.ts`）

| 改动 | 内容 |
|---|---|
| 缺口补全 | 改为**取有效射线的中位数**（无方向性偏置）—— 缺口 = "该方向没撞到墙"，最稳的估计是"其余方向的典型半径" |
| 朝外扩展前提 | 新增 `SCAN_GROW_MIN_HIT = 0.85`：**起点与每一档都要求内壁完整围住**才认（余下三道闸门不变） |
| 绝对尺寸闸门 | 新增 `ANCHOR_PORT_MAX_N = 0.06` + `clampAnchorPort()`：半径超舰长 6% 即**整体等比缩回**并 `console.warn` 点名 |

另：巡览面板读数补上"**实际光斑直径 x.xx% 舰长**"（含缩放与上限），并在触发上限时标 `⚠已按绝对上限缩回`
—— 画面与数字必须能对上，不再靠猜。新增诊断探针 `_fx_anchor_inventory.cjs`（纯字节解析 GLB，
列出**全库**带 FX 锚点的模型 + 缩放 X 是否留在 1 + extras）与 `_fx_repro.cjs`（连运行中的 dev server 取真值）。

## 5.5 [v28d] 用户实拍「外面一圈会穿模 + 不够精致」

> 「现在**里面的那个部分是对的**，但是**外面一圈会穿模**，但我觉得这个外面一圈**似乎意义不大**，
> 而且**不够精致**，可以更精致点，尤其是**不要穿模**。」

### 5.5.1 根因（三条，两条是我自己上一版引入的，一条是几何库的固有性质）

| # | 根因 | 证据 |
|---|---|---|
| 1 | **柔晕层放大 1.8×**：白核自 v28 起是"按内壁量到边"（wall-to-wall），再 ×1.8 **必然**捅穿内壁 | 实测暖晕可见半径 = 开口 ×**1.80**（0.5608 vs 0.3116） |
| 2 | 上一版给柔晕**材质漏了 `vertexColors: true`** ⇒ 写进几何的 `edgeFade` 顶点色**根本没被读取**（死代码）⇒ 暖晕仍是**满幅硬边琥珀板** = 用户说的"外面一圈"；硬多边形边 = "不够精致" | `matFlags` 读回 `glow:false`；渲染图里金板盖在舰体面板上 |
| 3 | 白核封盖来自 `ExtrudeGeometry` 的 **earcut 三角化，不产生内部顶点** ⇒ 全部顶点落在轮廓上（`f≈0`）⇒ 逐顶点**径向渐变塌成"全黑片"**，光核直接消失 | 实测中心顶点色和 **0.007**（应为 3.0）、中位 **0.507** |

### 5.5.2 修复（`battleFx.ts`）

| 改动 | 内容 |
|---|---|
| 新增 `buildFanPlate(pts, thick)` | **中心 + 轮廓**的扇形挤出（含中心顶点 ⇒ 径向渐变成立；侧壁全在轮廓上 ⇒ 天然最暗）。`outline` 与 `round` 两档都走它（圆口用 **48 段**椭圆，旧的 16 段圆柱封盖渐变呈 16 瓣）；矩形改 `BoxGeometry(…,3,3,1)` 以产生内部顶点 |
| 柔晕不再放大 | `rMul 1.8 → 1.0`：两层**共用同一套开口尺寸** ⇒ 可见能量全部落在开口以内 |
| 两层都开 `vertexColors` | `edgeFade`：白核 `0.55`（55% 半径内满亮、向外 smoothstep 收到黑）、暖晕 `0.0`（满幅平滑衰减）。加色混合下**黑 = 不加任何东西** ⇒ 硬边收成光，且**越界部分物理上不可见** |

| 1 | 1.76% | 2.43% | **3.98** | 4.2% | 1 | 平滑 + 楔形 |
| 2 | 1.84% | 3.67% | **3.96** | 13.5% | 6 | 成串 `4.05` 与 `1.84` |
| 3 | 1.82% | 3.54% | **3.74** | 11.5% | 4 | 成串 `4.00` 与 `1.82` |

剖面里的**成串相同值**是两条假边：`1.84` = "缺口填全局中位"、`4.05` = "夹到 `2.2×中位` 上限" ——
两者之间**一刀径向跳变** ⇒ 扇形板上就是那根尖端收细的楔形（= 用户圈的"交叉长条"）。

`THREE.Raycaster` 独立复核**命中面朝向** `dot(n, dir)`：

| 命中 | n | dot 中位 | 判读 |
|---|---|---|---|
| 近命中（r < 1.5×中位） | 60~96 | **−0.91 ~ −0.99** | 腔内壁（正对锚点） |
| 远命中（r > 2×中位） | 6~13 | **−0.35 ~ −0.39** | **掠射**（擦着面滑出去）⇒ 不是墙 |

### 5.6.2 根因（三层，逐层去掉后剖面才干净）

| # | 根因 | 证据 |

## 6. 已知边界（写清以免被当成 bug）

1. **星形域**：量到的是"从锚点看得见的那圈内壁"。喷口（口内壁一圈）天然满足；
   "包裹超过 180° 的月牙形"其凹进部分会被弦取代。
2. **朝外扩展的上限** = `0.5 × 搜索半径`（搜索半径 = `max(采信半径×3, 6% 舰长)`，夹 25% 舰长）。
   口比这个更深时，量到的是能走到的那一刀 —— 想直接量口沿，把空物体往口沿挪一点即可。
3. **别把空物体精确贴在平面上**（共面三角形不挡光）。
4. **别在同一个喷口里放两个空物体**（会得到两片重叠的光）。
