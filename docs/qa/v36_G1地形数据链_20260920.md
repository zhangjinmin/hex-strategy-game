# G1 · 空域地形数据链修复（v36，2026-09-20）

> ⚠⚠ **本文的验收结论已被 `v36c_地形可见性_20260920.md` 修正，请以 v36c 为准。**
> 本文的 9 条判据**全部成立但不够**：它们只验了"地形斑对象已生成"与
> "`getTerrainEffect()` 不再中性" —— 这是**数据链路**判据。
> 用户实机回报"界面上什么都没有"，实测根因是
> `body.battle3d-mode #phaser-canvas-container canvas { visibility: hidden }`
> ⇒ 指挥制下**整个 Phaser 画布被隐藏**，本文所依赖的地形斑**结构性不可见**。
> 教训：判据必须覆盖到"用户实际感知的那一层"；"对象存在"≠"看得见"。

> **来源**：`docs/qa/v35_四问诊断_20260920.md` 的第一问 ——
> 「地图中是有各种空域地形的，我现在就一个中继点」
> **性质**：**"东西做了但没接上"**（生产端 ✓ / 消费端 ✓ / 中间漏搬字段）
> **结果**：断点定位 → 修复 → L2 验收 **9 PASS / 0 FAIL**

## 1. 结论

**两个断点，都已修**：

| # | 断点 | 位置 | 后果 |
|---|---|---|---|
| **B1** | `renderHexMap` 重建 tile 对象时**漏搬 `terrain` 字段** | `BattleScene.ts:2145-2150` | `getTerrainAt().terrain` 恒 `undefined` ⇒ **六处消费者全部空转**（移速/射程/闪避/索敌/持续损伤/地面标记） |
| **B2** | 指挥制把地形标记渲染挡在 `else` 之外 | `BattleScene.ts:535-544` | 指挥制下地形**完全不可见**（而 `battlefieldMode` 默认值就是 `command`） |

**为什么 B1 是"漏搬"而不是"没做"**：`buildMapData()`（`:3892`）确实注入了 6 种地形
（`:4059-4066`，共 27% 密度），且其返回值**直接**作为 `renderHexMap(mapDataMatrix)` 的入参
（`:454` → `:534`，同源同序）⇒ 数据一路都在，只在重建 tile 对象时掉了。

## 3. 改动（4 处）

| 文件 | 改动 |
|---|---|
| `config/balance.ts` | `TERRAIN_RULES` 新增 **`BATTLE_ENABLED: true`** —— 地形效果**总开关**（一键回到"有视觉、无效果"） |
| `config/terrainEffects.ts` | `terrainEffect()` 入口加总开关守卫（一处控住全部五项） |
| `game/scenes/BattleScene.ts` `:2145` | tile 字面量补 **`terrain: data.terrain`**（B1） |
| `game/scenes/BattleScene.ts` `:535-544` | 去掉 `else` ⇒ 指挥制**也**调用 `renderTerrainMarkers()`（B2） |
| `game/scenes/BattleScene.ts` `renderTerrainMarkers` | 新增 **command 分支**：不复用被隐藏的 hex sprite，改为另画"空域斑"（无描边淡色圆 + 危险地形细描边），并给对象 `setName('terrainBlob'/'terrainBlobRing')` 供验收计数 |

**为什么指挥制不直接显示 hex**：`:536` 的注释写明"纯宇宙：隐藏六边形地块"（刻意设计，
配合 `drawCommandSpace` 的等高线风格）。直接恢复 hex 会破坏该美术方向；
改画**无描边淡色圆斑**既让地形可见、又读作宇宙里的雾区/碎石云/引力涡旋。

## 5. ⚠ 这是**行为变更**，不是纯修复

补上字段后，五类效果**第一次同时生效**：

| 效果 | 值域 | 影响 |
|---|---|---|
| 移速 | ×0.55 ~ ×1.30 | 星云/机雷区明显变慢、引力点加速 |
| 射程 | ×0.70（小行星带） | 带内交火距离缩短 |
| 闪避 | ÷1.20（星云） | 星云内更难被命中 |
| 索敌 | ×0.80 ~ ×0.96（已按 `VISION_STRENGTH=0.45` 削弱） | 地形内**发现敌人更晚** |
| 持续损伤 | 机雷 1.5%/3s、杰夫 0.8%/3s | 久留会掉血 |

⇒ **战斗节奏会变**（尤其 23.9% 的格子都带地形）。
**一键回退**：`balance.TERRAIN_RULES.BATTLE_ENABLED = false`
（回到"地形可见、无数值影响"；若连视觉也要关，把 `:543` 那行注掉即可）。

**建议真机确认**：① 地形斑的**淡色圆**在指挥制风格里是否顺眼；② 23.9% 密度是否过高
（密度由 `:4059-4066` 的 roll 阈值决定，调低即减密度）。
