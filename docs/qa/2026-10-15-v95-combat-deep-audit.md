## 2. 交叉审核（我做的裁决）

### 2.1 两路对 M2 的判断有分歧 —— 我的裁决

- **任务 ③** 说 M2「可能让我方吃亏」；**任务 ①** 说 M2「让目标防御趋近 0（**对攻击方有利**）」
- **裁决**：`effectiveDef = (受击方 def) / (攻方同型数)` ⇒ 它**总是削弱"受击方"、利好"攻击方"**。
  ⇒ 双方**各自用自己的同型数削对方防御** ⇒ **谁的同型实体多，谁就占优**。
  ⇒ **方向取决于舰队构成**，**不能单独解释"我方全灭"**（若我方是同型大编队，反而我方可占优）。
  ⇒ **但它是明确 bug**（防御应由**受击方**自己的分母口径决定），必须修。

### 2.2 实锤核实（我亲自验证的两条）

| 断言 | 核实结果 |
|---|---|
| 我方僚舰是 `type:'ai', team:1` | ✅ `:5133` `type: index === 0 ? 'player' : 'ai', team: 1` |
| 演习轨道倍率恒等（提督属性无效） | ✅ `:1505` `const mods: ShipStatMods = { hpMul: 1, atkMul: 1, defMul: 1, engineMul: 1 }` |

## 3. 结论：三个问题的根因

### 3.1 「友军不动」

| 层 | 状态 | 性质 |
|---|---|---|
| 玩家旗舰舰队（`type:'player'`） | 无命令 ⇒ **保持初始部署** | **设计**（`9c099a5` + 设计文档明文） |
| **我方僚舰（`type:'ai', team:1`）** | 本应 AI 自主 ⇒ **但 `_deployTactic` 被 `75384ed` 断供** ⇒ `deployAdj` 恒 **1.15（最保守）** | **⚠ 真实回归** |
| 提督个性（如绕侧） | `shouldFlank` 的 `commanderAggressive` **未使用** | **功能缺失** |
| AI 托管开关 | **不存在** | 需新建 |

### 3.2 「提督属性高一大截」

**该前提不成立**：
- **演习轨道**：倍率恒等 ⇒ **提督属性完全不进单舰数值**
- **战役轨道**：`÷同型实体数` ⇒ 200 实体时占比 **<1%**
- **hard 难度**：敌方提督 **+30** ⇒ 可能**反超**

### 3.3 「对射被全灭」

机制链（按贡献度）：
1. **提督属性不生效** ⇒ 只剩兵力优势
2. **站桩对射**（M1）⇒ 纯乘区对拼，机动无法扳回
3. **乘区被吃掉**：阵地互克（1.86×）/ 补给断崖+难度不对称（M3）/ 防御乘区取错（M2）/ 最小伤害保底（M5）/ 突击不还击（M6）
4. 若我方为**少数精舰**：M5 保底让敌方（多单位）更占优
5. 若我方**推进远**：补给先崩 ⇒ 2~3 层衰减叠加到 ≈15%
