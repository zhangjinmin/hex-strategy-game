# v41b · 掉头协议（原地转身）—— 「整个阵型绕原点画圈」的结构性根因

> **日期**：2026-09-21
> **触发**：用户追问「掉头机制究竟怎么弄的，为什么还是整个阵型沿着一个原点画圈，而不是每艘战舰自身原地旋转变向？卡在哪里？」
> **结果**：卡点定位（判据测不到掉头的结构性死结）→ 掉头协议实施 → 台架 **7 PASS / 0 FAIL**、L2 **7 PASS / 0 FAIL**、`vue-tsc` 0

## 1. 掉头机制的真实链条（修复前）

```
目标方向突变为反向
   ↓
① 位移方向 = facingSmooth          ← :5296（v34b「位移与推力自洽」，这层是对的）
   ↓
② facingSmooth = 慢速低通          ← HEADING_TURN_RATE = π/240 ≈ 0.75°/帧 + 角加速度惯量
   （180° 要 ~300 帧 ≈ 5 秒）
   ↓
③ v41 的吸附判据 = |moveDir − formFacing|
   而 moveDir 是【实际速度方向】——弧线转弯时它和 formFacing 一起慢转
   ⇒ 两者的差永远 ≈ 0
   ⇒ 吸附分支【结构性永不触发】      ← 卡点！判据测不到掉头
   ↓
④ v34b 把 THRUST_IDLE 提到 0.45    ⇒ 掉头时仍有 45% 推力（不是"原地"，是"边走边转"）
   ↓
结果：位移方向以 0.75°/帧 慢转
   ⇒ 中心航迹 = R = v/ω = 0.30 × 240/π ≈ 23px 的小圆
   ⇒ 整个阵型像刚体绕一个 23px 的原点画圈转向（用户实报）
```

**为什么报了这么多次都没修掉**：v34 只 snap 了 `formFacing`（阵位真源），v41 只是把 snap 阈值从 150° 降到 90°——**两代修复都没碰真正的驱动源 `facingSmooth`，而且判据（moveDir vs formFacing）在这套低通系统里结构性测不到大角度差**。判据错了，阈值调多少都没用。

## 2. 修复：掉头协议（`balance.FACING_TURN` + `BattleScene` 低通块）

| 参数 | 值 | 语义 |
|---|---|---|
| `ENTER_RAD` | 50° | 目标航向差 > 50° 进入协议（滞回进入阈值） |
| `EXIT_RAD` | 30° | 差 < 30° 退出，恢复正常巡航转向（ENTER > EXIT 防抖动） |
| `RATE_MUL` | 6 | 协议期转身速率 = 0.75°×6 = 4.5°/帧 ⇒ 180° 约 **41 帧 ≈ 0.67s** |
| `THRUST` | 0.06 | 协议期推力压死 ⇒ 速度 0.018px/帧 ⇒ **航迹弧半径 0.23px = 原地** |

协议期三件事同时做（缺一都会退回画圈）：
1. `facingSmooth` 快档转身、无惯量（位移方向的根被拔掉）；
2. `formFacing` 每帧同步 = `facingSmooth`（阵位/托盘/位移**一个真源** ⇒ 整阵绕锚点刚性旋转，单位连续跟随自己的旋转格位，**不走位重排、不穿心**）；
3. 推力压到 0.06（"原地"的保证）。

这正是用户要的语义：**每艘战舰自身原地旋转变向，转完直线出发**。

⚠ 判据教训（防复发）：**速度方向（moveDir）是控制的输出，不是误差的度量** —— 闭环控制里不能用被控量的衍生量当误差源。误差必须用「目标航向 − 当前朝向」（fAngle − facingSmooth）。

## 4. 实施自查

1. 又一次 splice 吃闭合括号（外层惯量块 `{`）—— vue-tsc 抓到后补回。同一类坑第三次（v37/v41/v41b），**行级 splice 必须连带检查前后各一个块边界**。
2. 台架 2 处判据错：④ 把「过程中最大残差」当「终点残差」（第一帧 facing 在起点，残差恒 = π）；② 对照断言方向写反。修正后台架 7/7。
3. 90° snap 分支（v41）保留作兜底——协议生效后 `_dTo ≈ 0`，snap 自然不再触发，两者无冲突。
