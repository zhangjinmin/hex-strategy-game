## 2. 台词体系结构

- **事件台词**（接敌/受创/占领/溃灭…）：战场气泡（跟随舰船），既有 `showFleetDialogue` 不变。
- **战中闲聊 banter**：右上立绘对话卡（`store.showDialog`），与事件台词语境分离，防连续重复同一句。
- **入场致辞**：名言「」+ 简报（占位符插值敌我舰队数）+ 口令，三段各自随机。
- 覆盖：14/182 提督有专属（莱因哈特/杨威利/米达麦亚/罗严塔尔/奥贝斯坦/吉尔菲艾斯/缪拉/毕典菲尔特/梅尔卡兹/比克古/先寇布/波布兰/亚典波罗/卡介伦），其余落 general 兜底。

## 3. 验证中发现并修复的真缺陷

`emitBanter` 初版"随机选人 → 不可见才 return"：随机选中战争迷雾中的敌舰会**静默吞掉一次发言配额**（排程已重排而实际没开口）。已改为选人前按可见性过滤（己方 ∪ 视野内敌方）。

## 4. 探针环境注记

SwiftShader 低帧率下 Phaser `time.now` 走慢（真实 48s ≈ 17s 场景时间），探针以 `nextBanterAt = now + 1.5s` 注入缩短首句排程复测；选人/选池/防重复/触发链全部走真源码。真机 20-60fps 下场景时钟与真实时间一致，闲聊节奏即设计值（25s 首句、30~55s 间隔）。
