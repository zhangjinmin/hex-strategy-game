# v58 旗舰浮动气泡（去右侧立绘对话框）— 定量验证报告

日期：2026-09-22　范围：战中提督闲聊（banter）呈现方式改造 + 气泡互不遮挡

## 1. 问题与决策

**用户反馈**：右侧跳出的立绘对话框会被「军议任务指令」侧栏遮挡；期望改为**旗舰位置的精致浮动框，一句话即可**，且互相不遮挡。

**第一性原理审查结论**：
- 真实目标 = 闲聊信息在不被 UI 遮挡的前提下送达。右侧立绘卡与军议侧栏（CouncilWarRoom）争夺同一屏幕区域，是结构性冲突，位置微调（下移/左移）都只是转移遮挡。
- 战场已有成熟的舰船跟随气泡（`showFleetDialogue`，事件台词在用），复用它是零新增渲染路径的最短解。
- 替代方案（HTML 层旗舰锚定气泡、Canvas 独立层）均需新建跟随/投影换算逻辑，成本高于复用 Phaser 气泡，收益相同 ⇒ 不采用。
- 「一句话、不互相遮挡」⇒ 采用**单例气泡**语义：任意时刻至多一个在场气泡，新发言先销毁旧气泡。代价：双方同时接敌时后一句会顶掉前一句，符合"出现一句话就可以"的期望。
