  - ⇒ **绝对 fps 不代表用户核显/独显真机性能**。

### V2 · 删旗舰竖直光柱 — **PASS**（慢转 CONCERNS）

- **源码级**：全文检索「光柱」= **0 处**（旧版 8 处）；`attachFlagshipFx` 方法体 693 字符，仅构建 `RingGeometry(r*0.90, r, 48)` 水平细环，`CylinderGeometry=false`。
- **运行时**：3 艘在场旗舰均 `cmdRingType=RingGeometry` 且在 `children` 内；`ringKids=[1,1,1]`；`fxCylinderChildren=0`；旗舰 group 子对象几何类型全表 = `["BufferGeometry","EdgesGeometry","SphereGeometry","RingGeometry"]`，**不含 `CylinderGeometry`**。
- **CONCERNS 解释**：断言 `fxMaxGeoHeight=116.5487`（另一艘 68.558）。该值来自舰体 glow **大面片**（`SphereGeometry`/透明 additive 面片）与光环平面尺寸，**非柱体**（否则会见到 `CylinderGeometry` 且 `fxCylinderChildren>0`，实测均为 0）。⇒ 结论不变。
- **慢转**：`rotation.z` 1.2s 内 0.22 → 0.2475（**+0.0275**），方向正确（`FLAGSHIP_RING_SPIN=0.55 rad/s`），但步进小于阈值 0.05 —— 系 SwiftShader 低帧率下采样窗太短所致，记 **CONCERNS**（不否定慢转事实）。
- **视觉对照**：`v12_旗舰对照_旧vs新.png`（676860 B）左 1 = v2 `93_grand_fleet_close.png`（**可见旧竖直光柱**），左 2 = v6 `d800_dots_only.png`（旧竖直柱仍在），右 = v12 `v12_旗舰近景.png`（**仅水平细环，无竖直柱**）。旗舰近景 `v12_旗舰近景.png` 1963376 B。

### P1 · `antialias:false` + `high-performance` — **PASS**

- **运行时** `getContextAttributes() = {"alpha":true, **"antialias":false**, "depth":true, "powerPreference":"high-performance", "premultipliedAlpha":true, "stencil":true, …}`。
- **源码**（`Battle3DOverlay.ts` 1258-1262）：`new THREE.WebGLRenderer({ antialias:false, alpha:true, powerPreference:'high-performance' })`；设计理由 = 本层只两次 render，**画布级 MSAA 对全屏 quad（合成）无效**，故关闭。
