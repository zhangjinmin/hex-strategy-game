## 1. 三个来源

### ① 呼吸动画 —— 「摇头晃脑」的直接来源

`BattleScene:5534-5535`（v21 JIT-2 引入）：

```
breatheX = sin(time*0.0012 + slotIdx*1.7) * 1.2 * breatheEnv
breatheY = cos(time*0.0015 + slotIdx*1.3) * 1.2 * breatheEnv
```

**每艘舰相位不同**（`slotIdx×1.7` / `×1.3`）⇒ 各晃各的；且 `isStopped` 的判定包含 **`isEngaging`**（`:5489`）⇒ **交战舰队一直在"沸腾"**。这就是「敌方舰队左右晃动」和「摇头晃脑」的同一来源。

**处置**：整段删除（包络 + 位移 + `targetUnit` 项）。实测 `facingSmooth` 变化 **0.0000 rad**（修复前呼吸期每舰 ±1.2px 各自抖动）。
⚠ 该效果的原意是"停泊时的生命感"，但舰队应是整齐队列——1.2px 抖动在 3D 层放大后肉眼可辨，收益为负。

### ② 交战中也压推力 —— 「缩成一团」的直接来源

协议期 `thrustFactor = FACING_TURN.THRUST (0.06)` **无条件生效** ⇒ 交战中一旦触发协议，**全队瞬间停住**、200 艘挤在一处 = 「缩成一团」；协议退出后恢复 ⇒ 「展开」。

**处置**：压推力加条件 `isEngaging !== true`——协议压推力是为「脱离/巡航掉头时原地转身」，战斗中不该停。

### ③ v42 删掉了转向纪律 —— 「狂转」的另一半

我在 v42 重构时把 `turnDiscipline` 的消费整段删了 ⇒ **交战中也会全速转身**（6× 速率）。

**处置**：以正确形式恢复——作用在**舰体速率**（不是格位）：

```
uStep = HEADING_TURN_RATE × RATE_MUL × turnDiscipline(...).rateMul × dt
```

交战中大角度 ⇒ `denied` ⇒ `rateMul` 0.06~0.16 ⇒ 不狂转（用户 v40 的原始规格「还在对战就不能转向」）。
