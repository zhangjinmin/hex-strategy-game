# v56 · 性能优化（近景帧率 + 齐射爆降）— 定量验证报告

日期：2026-09-22 ｜ 诉求：远景 60fps、近景（舰船模型）仅 20+fps、齐射时帧率爆降，要求整体帧率提升。

口径声明：以下数值均为 **SwiftShader 无头探针、同机前后对比**（绝对值 ≠ 真机 GPU；真机验收仍须 L3 人眼）。
探针：`_probe_v56_perf.mjs`（基线/复测）+ `_probe_v56_fill.mjs`（瓶颈归因）+ `_probe_v56_dpr.mjs`（动态分辨率确定性验证）。
`vue-tsc --noEmit` EXITCODE=0。

## 1. 根因（三条独立问题）

| # | 根因 | 影响 | 修复 |
|---|---|---|---|
| 1 | 齐射特效逐发新建 CylinderGeometry / MeshBasicMaterial / CanvasTexture（命中贴图逐次 canvas→GPU 上传） | **齐射爆降主因**：单波 120 激光+60 命中 ≈27ms 纯 JS 构建，过期回收再尖峰 98ms | 单位几何单例 + 材质/Sprite/贴图对象池（POOL_CAP=384）+ 命中贴图按色缓存 |
| 2 | `tick()` 双重调用块（v37 重构回归）：updateFlames/drainFx3d/updateFx/updateBoats/updateCaptures 连续跑两遍 | 每帧白烧一倍 CPU，且特效 2× 速播放 | 删重复块（`pre_refactor_backup` 佐证为单份） |
| 3 | `buildEnginePortGeo` 逐舰重建合并几何；`missileStep/shieldFire` 逐帧 new Vector3 | 近景 tick 尖峰 | 参数 key 缓存（`__b3dShared`）+ 暂存向量 |

另：近景分辨率/填充开销无自适应手段 → 新增**动态分辨率**（下文 §4）。

## 3. 近景瓶颈归因（决策依据存档）

- 分辨率减半对照（dprCap 2→0.5）：rafMed 1183→1287 **基本不变** ⇒ SwiftShader 下近景非纯填充率瓶颈，
  以 draw call（~930）/ 对象数为主。真机 GPU 上填充率贡献**不可**用此口径排除。
- Phaser 场景渲染已确认被跳过（`sys.settings.visible=false`），无重复渲染。
- **否决**：flame+glow 合并（可省 ~200 draw call）——损伤时两者独立着色
  （`Battle3DOverlay.ts:3735-3738`）会丢失视觉语义，不为性能牺牲。

## 4. 动态分辨率自适应（新增，确定性验证 2 PASS）

机制：`updatePerfGovernor` 帧时 EMA > 22ms ⇒ `dprScale ×0.85` 收缩至下限 0.6（≈36% 像素量）；
< 15ms ⇒ `×1.12` 缓慢回升至 1（滞回防振荡）；`effDpr()` 统一 renderer.setPixelRatio 与离屏 RT 尺寸。

| 阶段 | dprScale 轨迹 | RT 宽度 | 判定 |
|---|---|---|---|
| 收缩（ema≈50ms） | 1 → 0.722 → 0.6（单调✓） | 1584 → 950 | PASS |
| 回升（ema≈5ms） | 0.6 → 0.672 → 0.753 → 0.843 → 0.944 → 1（单调✓） | 950 → 1584 | PASS |

取舍：持续超帧预算时以清晰度换帧率（下限 0.6 保 UI 可读性），流畅后自动回满，用户无感。

## 5. 用户侧杠杆

- 设置·画质档 medium/low：dprCap 1.5/1 + MSAA 2/0，近景收益最直接。
- `battle3dPerfGuard`（默认开）：meshBudget + dprScale 双通道自适应的前置开关。
- `shipModelDetail` 降档：减少舰体三角数。
