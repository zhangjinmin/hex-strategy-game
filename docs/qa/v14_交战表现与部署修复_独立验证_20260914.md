## 4. ③1 morph 真实时长（v14.1 修复点，重点）

### 4.1 v14.1 修复的**单位错误**（静态逐字 A/B）
- **after（v14.1）** `BattleScene.ts:4046`：`_formMorphT = Math.min(morphDurNow, morphTNow + (Math.min(delta,100)/1000) * dt)` —— **真实时间积分**（秒）；
- **old（v14）** `_ws16_mod_BattleScene.txt`：`_formMorphT = Math.min(morphDurNow, morphTNow + dt)` —— 把**速度倍率 `dt` 误当单位** ⇒ 只计帧（speedFactor=1 时每帧 +1 ⇒ **第 4 次**即到 3.5，与 delta 无关）。
- `FORMATION_MORPH_DUR = 3.5`（秒）。

### 4.2 合成 delta 驱动（**自建输入，非照抄工程侧 delta 组合**）
在 `page.evaluate` 内用**同步 for 循环**调 `sc.update(now, D)`，逐次读 `f._formMorphT`（页内原子执行，**零 RAF 交错**）。每个序列前强制结束上一段 morph（`_formMorphT = _formMorphDur`）避免"过渡中不响应二次换阵"的排队语义污染，并**真换阵**（`wedge↔line`）：

| 序列 | 输入 delta / speed | 实测单步增量 | 首次 ≥3.5 索引 | 备注 |
|---|---|---|---|---|
| S1 | 50 / 1 | **0.05** ×6 | 70~71 | 第 20 次 = **1.000**；末值 = **3.5** |
| S2 | 25 / 1 | **0.025** | — | 与 delta 线性 |
| S3 | 200 / 1 | **0.1** | **34** | delta 夹紧 100ms ⇒ 0.1/步 |
| S4 | 100 / 3 | **0.3** | **11** | ×speedFactor ⇒ ≈3.5s/3≈1.17s |

⇒ 与静态推导一致：`(min(delta,100)/1000) × speedFactor` 每步，1× 全长 **3.5 秒**、3× ≈ **1.17 秒**。**v14 的"3.5 帧"错误已被修复**。

### 4.3 **真实位移层**（比计数器更硬，独立于公式）
受控换阵 + 固定 delta 推到 `T=1.75`（`morphE = smoothstep(0.5) = 0.5`）；因舰队自身仍会平移（`dt` 驱动、非 delta）导致 sprite 滞后，故**钉住舰队**（收敛循环内复位 `f.x/f.y`）消除漂移，并读 **sprite 的舰队局部偏移**（逆旋转）：
```
slot=116  |B−A|=530.17px
A=[-260,221]  B=[-60,-270]  mid=[-160,-24.5]（A/B 线性中点）
local=[-160.712,-21.945]
errMid = 2.652px   errA = 262.451px   errB = 267.720px
```
⇒ 实测位移**几乎精确落在旧/新中点**（残差 2.65px ≈ 停泊呼吸 `breathe` 幅度 ≤1.7px），**远小于**到任一端点的 262/268px。⇒ `morphE=0.5` 时"位移 ≈(旧+新)/2"成立。

### 4.4 smoothstep 曲线形状（实测位移，非公式自证）
多 checkpoint 收敛后量局部偏移，逐段算 `|Δoffset|/ΔT`：
```
pts.T     = [0.05, 0.7, 1.4, 1.75, 2.1, 2.8, 3.45]
slopes    = [72.66, 187.31, 224.55, 224.19, 187.70, 84.98]
```
⇒ **两端小（72.7 / 85.0）、中段大（224.6 / 224.2）** —— 缓入缓出（smoothstep）曲线形状成立。

## 5. ③2 转向限速 30°/s

静态：`SHIP_TURN_RATE = Math.PI/6`（= 0.523599 rad/s = **30.0°/s**）；`approachAngle(cur,target,maxStep)` 用 `atan2(sin,cos)` wrap（自测 359°→1°：Δ=**+0.010000**，非绕远路 -6.27）。

运行时注入受控 dt（`ov.syncShips(0.05)`），采单舰 `group.rotation.y` 单帧增量（注入 +90° 目标）：
```
每帧上限 = SHIP_TURN_RATE × 0.05 = 0.0261799
前 6 增量 = [0.02618, 0.02618, 0.02618, 0.02618, 0.02618, 0.02618]
maxDiff = 0.02618   nJumps(>0.1rad) = 0   errFirst = 1.5446 → errEnd = 0
```
⇒ 单帧 \|Δyaw\| **恰好被钳在 0.02618**（=30°/s×0.05s）、**无任何瞬跳**、最终收敛。**限速成立**。（工程侧 before 单帧 ~2.59rad 瞬跳 → after 0.0262，独立复现一致。）

## 6. ④ 撤退朝向（facingAngle 权威 + 限速）

## 11. 台架方法学与局限（可复现性）

- **确定性驱动**：所有运行时断言均在 `page.evaluate` 内以**同步循环**完成（`sc.update(now, D)` / `ov.syncShips(D)`），`page.evaluate` 原子执行 ⇒ RAF 无法交错 ⇒ 零时序噪声。
