## 2. 问题①：LOD 未切换（根因是量化关系，不是 bug）

**实测链**（`Battle3DOverlay`）：

```
战列世界长度 L = 0.733 × √3 × hexR × 0.40
屏幕投影 px = L·H / (2·tan(25°)·d)
```

| 相机距离 d | 战列 px | 档位 |
|---|---|---|
| 1550（大图初始 `span×0.62`） | **9.9** | 纯光点（< MESH_IN_LO 14） |
| 806（小图初始） | 18.9 | 过渡带 |
| 650 | 23.5 | 接近模型 |
| 500 | 30.6 | 纯模型 |

**两个真因**：
1. 初始相机 `span×0.62` 在大图上把 px 压到 10 以下 ⇒ **全军都是点**
2. 过渡带 `14~26px` 宽 12px，此区间点 alpha 仍有 0.78→0 ⇒ 模型与点重叠发糊

### 修复（三处参数）

| 项 | 旧 | 新 | 效果 |
|---|---|---|---|
| `MESH_IN_LO` | 14 | **9** | 更早开始长模型 |
| `MESH_IN_HI` | 26 | **15** | 过渡带 12px → **6px** |
| `MESH_KEEP` / `MESH_DROP` | 17 / 15 | **12 / 10** | px≥12 即分配实体 |
| 点让位 | alpha 连续衰减 | **grow>0.55 时点完全消失** | 消除"模型+点"重叠 |
| 初始相机 | `span×0.62, hexR×24` | **`span×0.50, hexR×20`** | 初始视角即达纯模型档 |

单调关系保持：`MESH_IN_LO(9) < MESH_DROP(10) < MESH_KEEP(12) < MESH_IN_HI(15)`。

实测：`span=1300 ⇒ d=650 ⇒ px≈23.5`；`span=2500(hexR=50, L=25.4) ⇒ d=1250 ⇒ px≈23.5`。

## 3. 问题②：运动学重构（新架构，不继承补丁）

### 3.1 为什么之前四轮都失败

v70 / v71 / v72 连续改错。复盘根因：**都在「追槽位」架构内调参数**。

旧架构四个量互相耦合：
```
fAngle(火控) → facingSmooth(舰首) → formFacing(阵面) → 位移方向
```
任一变则全变 ⇒ 阵型指向与移动方向不一致、公转画圈、挤压、瞬间换向。
**问题在结构，调参无法收敛。**

### 3.2 第一性原理：核心物理约束

```
保持编队需要横向速度：v_外翼 = ω × 编队半宽
⇒ 编队不散架的硬约束：ω ≤ vMax / halfWidth
```

**这不是"参数没调好"，是物理要求**：一支宽 400px 的战列编队，若战列
vMax=0.22px/帧，则 ω ≤ 0.22/200 ⇒ 180° 掉头需 47.5s。
"掉头该慢"由此而来，而非手感问题。

### 3.3 新架构：舰队刚体模型

**把舰队当作刚体：一个质心 + 一个朝向。每艘船是刚体上的点，公式直算，不追。**

```
状态：fleet.x, y, heading, vx, vy, omega
每帧：推力→线加速度；力矩→角加速度；积分位置与朝向
每舰：ship.x = fleet.x + cos(h)·along − sin(h)·lateral   （公式直算）
每舰舰首：独立追火控目标（炮塔转速）
```

### 3.4 消灭的机制

| 旧机制 | 新方案 |
|---|---|
| `formFacing` 阵面朝向 | **删除**（阵面 = 舰队朝向，一体的） |
| `stepShipSlotFollow` 追槽位 | **公式直算** |
| 阵型 morph 插值 | 偏移量短时插值 |
| `facingSmooth` 追 `fAngle` | 舰首 = 刚体姿态 |
| `REFORM_SLOT_GAP_PX` / `maxSlotGap` | **删除** |
| `_slotFlip` / 格位反转 | 由偏移插值自然产生 |

**净效果：删除 6 个耦合机制。**

### 3.5 开发中抓到的控制律缺陷（台架实测）

初版 `want = sign(dH)·min(omegaCap, |dH|)` ⇒ 角阻尼每帧衰减、want 随 |dH| 收缩
⇒ 渐进收敛但**永不到位**（3000 帧到不了 180°）。

**这是制动律缺失**（与 v65 #18「过冲 179.9°」同类）。

修复：目标速率 = `min(omegaCap, √(2·alphaMax·|dH|))`（临界制动）+ 到位吸附。

### 3.6 一个必须记录的物理事实

**角阻尼让稳态角速度 = `omegaCap × (1−angDrag)`**，即实际转向比理论慢 `angDrag/(1−angDrag)`。

台架解析验证：实测 4479 帧 vs 理论 4480 帧（误差 0.02%），稳态 7.012e-4 vs 7.012e-4。
⇒ **这不是 bug，是阻尼的真实效应**，但文档必须写清楚，否则后人会当 bug 修。

### 3.7 编队宽度 → 掉头时长全景（设计自检）

| 半宽 | ω | 180° 掉头 | 外翼弧速 |
|---|---|---|---|
| 50px | 0.00330 | 15.9s | 0.165 |
| 100px | 0.00165 | 31.7s | 0.165 |
| 200px | 0.00082 | 63.5s | 0.165 |
| 300px | 0.00055 | 95.2s | 0.165 |

⇒ 大编队掉头会到 60~95s，**必须配"紧凑转"模式**（先收拢半宽再转）才可玩。
此项已列入设计文档 §4.1，本轮未实现。
