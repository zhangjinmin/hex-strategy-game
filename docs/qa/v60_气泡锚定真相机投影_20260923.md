# v60 · 浮动句气泡锚定改走真相机投影（实报"气泡飘在窗口外/别处"）

日期：2026-09-23 ｜ 验证：`_probe_v57_chatter.mjs` **10/10 PASS** ｜ `vue-tsc` EXITCODE=0

## 1. 实报与根因

**症状**（用户截图）：浮动对话框不出现在舰队上，被钉在窗口左缘（或飘到别处）；舰队实际在右侧。

**根因（投影坐标系不同源）**：v59 的 `worldToScreen` 用 **Phaser 相机**（`cam.worldView`+`zoom`）做
世界→屏幕投影，但指挥制下真实渲染相机是 **Three.js `Battle3DOverlay.camera`**——两台相机
独立维护（取景/缩放不同步），Phaser 投影结果系统性偏离屏幕真实位置，最后被视口钳位钉在边缘。

**判据缺口（v59 J9b 的教训）**：J9b"相机中心投影自检"只验证了 Phaser 数学**自洽**，
没验证"Phaser 相机 == 用户看到的相机"。判据必须打在**真实渲染链**上。

## 2. 修复（投影真源收口）

截图里舰队头上的 DOM 标签（舰队名/状态条）位置一直正确——`Battle3DOverlay.updateBillboards`
用真相机 `vec.project(this.camera)` + `container.clientWidth/Height` CSS 口径。**气泡改为复用同一条链**：

| 文件 | 改动 |
|---|---|
| `Battle3DOverlay.ts` | 新增 `public floatScreenPos(anchor)`：unit 锚吃本帧 `unitVis` 的 3D 位置（含地形/分层/档位，与渲染实体同位）；固定世界点锚（击毁语录）按 `(x, 巡航高, −y)` 映射；输出与 billboard 同口径 CSS px + `on`（视锥内）标志 |
| `BattleScene.ts` | 跟随块改 **overlay 投影优先**；2D 降级（无 overlay）才回退 Phaser 投影；`on=false` ⇒ 写 (−999,−999) 移出视口隐藏，**不钳在边缘** |
| `_probe_v57_chatter.mjs` | J9/J9b 重写为真实渲染链判据（见 §3） |

否决的替代路径：① Three 相机参数镜像回 Phaser（双相机同步是长期税，且 Phaser 画布已隐藏，
为死渲染链续命无意义）；② 气泡并入 billboard 层（耦合呈现层生命周期，改动面大）；
③ 维持 Phaser 投影+修钳位（治标：仍会偏离舰队）。
