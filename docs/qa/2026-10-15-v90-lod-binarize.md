# v90 LOD 二值化：近景=全模型 / 远景=全点阵

日期：2026-10-15。用户实报（附诊断面板截图）：
> 关于切近景还是有问题。刚开局，席特尼舰队是 20000 艘，
> 可以看到，**阵型中间空了一大块没有战舰**；
> **远景是粒子和模型同时存在**。

---

## 1. 面板数据（决定性证据）

```
tier=NEAR lo=24 hi=40 keep=22
n=200  px= 13.8  mesh=  0  DOT      ← 整支 200 艘全是小点
n=200  px= 63.4  mesh=200  MODEL
n= 80  px= 32.2  mesh= 80  MODEL
```

**同一视野内三支舰队的 `px` 差异巨大**（13.8 / 63.4 / 32.2）。

- **"阵型中间空了一大块"** = `px=13.8` 那支 200 艘舰队**全部是小点**（深色背景上几乎不可见 ⇒ 读作"空缺"）
- **"粒子和模型同时存在"** = 近的舰队是模型、远的整支是点

## 2. 根因：LOD 是**逐舰队按 px** 判定 ⇒ 同屏必然混合

`px ∝ 1/距离` ⇒ 不同距离的舰队 px 不同 ⇒ 档位不同。
用户要的从来是**二值**：**近景=全模型 / 远景=全点阵 / 中间不混**。

### 与 v84 的关系（本轮是一次修正）

v84 用户说"太远就出模型，没必要" ⇒ 我把门槛整体抬高（`14/26/17/15 → 18/22/24/40`），
但**近景档也用同一套门槛** ⇒ 近景时**远处舰队仍被判为点** ⇒ 用户本轮看到的"空缺"。
⇒ 本轮把门槛**按缩放级别分两套**。

## 3. 修复：按缩放级别切换的两套门槛（二值化）

| 档位 | `lodKeep` / `lodDrop` | `lodLo` / `lodHi` | 效果 |
|---|---|---|---|
| **近景**（`lodNear`） | **0** | **0 / 8** | 所有舰队都建实体，px≥8 即实心 ⇒ **全模型** |
| **远景** | **999**（无人可达） | 24 / 40 | 无舰队建实体 ⇒ **全点阵**（雷达看全局） |

新增 `FAR_TIER_KEEP = 999`。

### 为什么这次能重启"两档"（v82 曾因抖动取消）

| 条件 | 说明 |
|---|---|
| ① 判据可靠 | 用**相机高度比** `camera.position.y / initCamY`（只受缩放影响）。v74 曾误用 `distanceTo(controls.target)` —— 被"跟随舰队"逻辑污染（只移 target 不移 position） |
| ② 滞回 | `0.75` 进 / `0.95` 出 |
| ③ 切换方向 | **近景档是"只增不减"**（远离景 ⇒ 实体增加）⇒ 不会批量销毁造成闪烁 |

### 验证（复刻 getter 逻辑）

```
近景档: {lo:0, hi:8, keep:0}     ⇒ px=13.8 的舰队 → 建实体（模型）✓
远景档: {lo:24, hi:40, keep:999} ⇒ px=63.4 的舰队 → 点（雷达）✓
```

## 5. 未闭合

- **`MAX_MESHES = 900`**：近景档下**所有**舰队都建实体 ⇒ 若视锥内实体总数 > 900 仍会挤出。
  本例 480（200+200+80）安全；更大场面需观察。
- **切换瞬间**：远景→近景时 480 实体需 `MESH_ADD_PER_FRAME=96` × 5 帧建完
  ⇒ 约 0.08s 内会短暂"点+模型"。若可感知，可再提高该上限。
- `MESH_KEEP` / `MESH_IN_LO` / `MESH_IN_HI` 现仅用于**远景档**；`MESH_KEEP` 目前
  已无消费者（保留备用）。
