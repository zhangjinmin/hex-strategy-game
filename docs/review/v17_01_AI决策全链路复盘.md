## 1. TL;DR（结论先行）

1. **敌我同构**：玩家舰队与 AI 舰队跑的是**同一份**每帧状态机（`this.globalFleets.forEach(fleet => {` :3556，对全体循环）。差异只有两处——**战略姿态 Tick 只跑 AI/盟友**（`filter(f => f.type==='ai'||'ally')` :501），**玩家能用命令改姿态/信标/任务**（`nearest.targetFlare=` :1598；`fleet.mission = m` :2075）。⇒ AI 舰队 = 无命令注入的玩家舰队；玩家舰队 = 有命令注入的 AI 舰队。
2. **没有"规划层"这个东西**：AI 的每一次决策都是对当前帧状态的即时反应（距离/血量/补给比阈值 → 改 `state`/`stance`/目标点）。**没有时间维度的计划、没有目标分配、没有阶段剧本输入、没有再规划触发**。（用户想要的"开战前规划再进场"在现状**完全不存在**，详见 §6。）
3. **最强的一条结构性缺陷**：AI 战略层**只评估每个阵营的 `fleets[0]`**（`const fleet = fleets[0];` :504）——若某 AI 阵营有多支舰队，**只有第一支**会得到战术姿态更新，其余永远停在初始 `'search'`。
4. **协调近乎为零**：全代码只有 3 处弱协调——`alliesOnTarget`（限制每目标 ≤2 队，:3743 / :3955）、`claimedTargets`（探索目标降权 +2500，:4062 附近）、补给链运输舰分配（`SupplyChainSystem.ts` 目标筛选）。**没有全局目标分配器、没有编队级战术、没有谁守谁攻的角色分工**。
5. **纯反应式 + 无预测**：移动一律"朝目标当前坐标"（`rawVX = ...fleetBaseSpeed...` :4208 附近），**无拦截点/提前量计算**（全文件 `predict|intercept|lead|trajectory` 零命中）。对高速目标表现为"永远在追尾巴"。
6. **阈值僵化、难度不改智能**：决策阈值全是硬编码绝对值（`hpPct < 0.35` / `forceRatio > 2.0` / `hpPct < 0.3` / `supply<15` / `supply<75` …）；`selectedDiff` 只改**数值**（补给流失 `drainRate` :1355、铺地价 `aiPriceMul` :618、初始金 :3013），**不改决策**——"困难 AI"只是更富更耐打，不是更聪明。
7. **R10-A1 已修 3 处**（一句话）：补给 70↔80 死区（迟滞带）、信标期间不还手 / 信标盖断粮撤退（D1b）、占领完信标残留 + `_regrouping` 状态泄漏。**其余结构性缺陷仍未修**（§5.2）。

### 2.2 状态 / 姿态双轴模型

| 轴 | 取值 | 谁写 | 语义 |
|---|---|---|---|
| **`state`**（行为态） | `assembling` / `exploring` / `engaging` / `flaring` / `retreating` | 每帧状态机（唯一权威） | **做什么**（去哪、打不打） |
| **`stance`**（战术姿态） | `search` / `siege` / `defend` / `fallback` / `stealth` | 战略 Tick / 玩家命令 / 任务 | **怎么打**（打分权重、阵型、撤退触发） |
| 派生 | `formation` | 战略 Tick + 每帧 engaging 分支 + 命令 | 阵型（wedge / line / circle / spindle / square） |

> **关键不对称**：`state` 每帧被无条件重算（后写覆盖）；`stance` 是**低频写 + 高频读**。二者组合决定行为，但**没有仲裁表**——优先级完全由 `if/else if` 的书写顺序决定（`v16_03` 现象 B 的"信标盖撤退"就是顺序问题的产物）。

| **自身弹药** | `missileAmmo` 仅在开火时扣减（:4527），**决策层零读取** | 打空导弹的巡洋仍被当满配派去强攻 |
| **自身逐舰损耗** | 决策只看 `units[0].supply`（:3684）与总量 HP（:3677） | 单舰残血不影响"整队战斗力"判断 |
| **编队/队形状态** | `formation` 只被写、不被当作决策输入（除格位渲染 `n0` :4252） | 不会"保持战列线/合围到位" |
| **敌军撤退意图/航向** | 无目标速度/航向读取 → 无拦截点（全文件零 `predict/intercept/lead`） | 追尾巴（§5.2-B3） |

### A.2「AI 阵营多舰队」的战略层盲区

```
每秒 Tick（:501）对每个 ai/ally 阵营：
  fleets = globalFleets.filter(factionId === aiFac.id)   // 例：3 支
  if (fleets.length === 0) return;
  const fleet = fleets[0];                                // ⚠ 只取第一支（:504）
  ... 评估 forceRatio / 写 stance / 写 formation ...       // 仅作用于 fleets[0]
  // fleets[1]、fleets[2] 本 Tick 完全不参与战略评估
```

⇒ 若敌军主力出现在 `fleets[1]` 面前，`fleets[1]` 的 `stance` **不会**被调整为 `siege`/`fallback`，它只会被每帧状态机按当前 `stance`（默认 `'search'`）驱动——**没有战略层的"判断"，只有每帧的"反射"**。这正是"AI 愚笨"最直接的一处机制证据。
